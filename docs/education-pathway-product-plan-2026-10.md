# 港学荟教育路线产品线完整改造方案

> 版本：v1.0  
> 日期：2026-10-09  
> 核心范围：DSE、IB、A-Level 三条升学主线  
> 产品边界：其他升学出口保留，但第一阶段只做轻量说明和转介，不与三条主线争夺开发资源。

## 1. 产品定位

港学荟从「学校资料、学校报告和择校工具」升级为：

> **香港家庭教育路线规划与择校决策平台。**

平台不单回答「哪所学校好」，而是回答四个连续问题：

1. 孩子当前在哪个教育阶段？
2. 下一次要面对什么招生或升学节点？
3. DSE、IB、A-Level 哪条路线与家庭目标更匹配？
4. 当前应该使用哪个工具、报告或服务完成下一步？

产品不承诺录取结果，也不把路线测验包装成确定性预测。输出应该是「主路线 + 备选路线 + 下一决策 + 风险提示」。

## 2. 战略范围

### 2.1 核心路线

三条路线是产品、内容、数据和商业化的主轴：

| 路线 | 产品重点 | 主要出口 |
|---|---|---|
| DSE | 本地小学/中学衔接、选校、选科、DSE、JUPAS | 香港本地大学、非联招、海外、专上教育 |
| IB | PYP/MYP/DP衔接、课程结构、英文環境、海外升學 | 香港、英国、美国、加拿大、澳洲及其他地区大学 |
| A-Level | IGCSE → AS → A-Level、选科、课程成本 | 香港、英国及其他主要海外大学 |

### 2.2 轻量出口

以下路线保留，但暂不建设重型数据库和复杂推荐：

- 应用学习
- VTC／职业教育
- 副学位
- 重考
- 转校／转课程
- 继续教育

第一阶段只提供：路线简介、适合情境、与三条核心路线的关系、官方链接和转介说明。

### 2.3 当前不承诺覆盖的内容

当前网站已有幼稚园、小学报告和小一工具，但中学资料尚未完整。因此第一版不能宣传「已经覆盖完整中学规划」，应显示：

> 中学路线资料建设中；当前可先完成路线选择、幼小阶段规划和小学择校决策。

## 3. 用户和核心场景

### 3.1 内地来港家庭

重点问题：

- 不理解校网、派位和学校类型
- 不知道 DSE、IB、A-Level 的差别
- 需要简体中文解释官方文件
- 可能有跨境、搬迁或身份变化

### 3.2 本地幼小家长

重点问题：

- K1、小一和中一每个阶段如何衔接
- 计分、校网和志愿怎么做
- 现在选学校会不会影响以后路线

### 3.3 已在小学阶段、开始考虑中学路线的家庭

重点问题：

- 是否继续 DSE
- 是否转 IB 或 A-Level
- 学校课程是否真正提供完整衔接
- 未来大学地区和成本如何规划

### 3.4 已在中学阶段的家庭

重点问题：

- 选科和课程组合
- DSE／IB／A-Level申请材料
- 本地与海外大学申请节点
- 成绩不理想时的备选方案

## 4. 产品核心模型

### 4.1 六个必须同时考虑的维度

路线不是一个 `DSE / IB / A-Level` 标签，而是六个维度组合：

1. **教育阶段**：K1-K3、小一、小学、中一、中四、高中、毕业后。
2. **招生机制**：K1、小一自行分配、统一派位、直资/私立申请、插班、中一派位、大学申请。
3. **课程和资格**：本地课程、DSE、IB、IGCSE、AS、A-Level。
4. **升学出口**：本地大学、海外大学、专上教育及轻量其他出口。
5. **家庭约束**：预算、地区、交通、语言、身份、迁移、照顾安排。
6. **路线切换**：什么时候可以转、切换成本是什么、Plan B是什么。

### 4.2 学校数据不能只有一个课程字段

数据结构应从「学校 = 一条记录」升级为：

```text
Institution
  └── Campus
        └── Stage
              └── Programme
                    └── Qualification
```

因为同一机构不同校区、不同学段可能提供不同课程，不能把「英文教学」直接等同于「IB」，也不能把「国际化」直接等同于「A-Level」。

### 4.3 路线建议的输出结构

```text
主路线：DSE
匹配度：当前资料下较高
备选路线：IB
暂不建议：A-Level（资料不足，不代表排除）
当前阶段：K3 → 小一申请
下一决策：确认自行分配目标校
风险：预算、英文程度、家庭迁移计划尚未确认
建议产品：幼稚园报告、小一计分工具、学校比较、时间线
```

## 5. 用户完整流程

### Step 1：选择当前阶段

- 幼稚園
- 准备小一
- 小学低年级
- 小学高年级
- 准备中一
- 中学阶段
- 高中/大学申请

### Step 2：填写最少必要资料

第一版控制在 6—8 个问题：

- 孩子当前年级
- 居住地区
- 预算范围
- 中文/英文偏好
- 是否考虑海外升学
- 当前偏好 DSE、IB、A-Level 或未决定
- 是否接受跨区/转校
- 是否有额外学习支援需要

### Step 3：输出三张路线卡

路线卡包含：

- 适用家庭
- 典型阶段图
- 当前阶段下一步
- 课程和学校筛选条件
- 未来出口
- 主要成本和执行要求
- 需要继续核实的资料
- 可切换节点

### Step 4：进入路线工作台

工作台固定显示：

1. 当前阶段
2. 主路线和备选路线
3. 未来 30/90 天行动
4. 当前推荐产品
5. 已收藏学校和比较结果
6. 资料来源、核验日期和待确认事项

### Step 5：持续更新

用户完成一个阶段后，系统自动切换下一阶段，而不是要求用户重新开始。

## 6. 三条核心路线的产品设计

### 6.1 DSE 路线

#### 幼稚園至小学

- 幼稚園选择
- 小一自行分配
- 统一派位
- 校网、性别、宗教、语言和交通
- P1志愿结构

#### 小学至中学

- 中一派位
- 直资、私立和国际中学申请
- 一条龙/联系中学关系核验
- 学校课程和升中出口

#### 中学至大学

- DSE选科
- 学校实际开设科目
- 课程节奏和校内评估
- JUPAS、本地大学、海外和非联招
- 成绩复核、重考和备选出口

#### 主产品

- DSE路线评估
- 中学报告
- 中学课程比较
- 选科规划
- 本地大学出口资料

### 6.2 IB 路线

#### 幼稚園至小学

- 双語/英文環境
- PYP或相近小学课程
- 学習方式和家庭配合成本
- 中英文基础是否足以支持转换

#### 小学至中学

- PYP → MYP → DP 是否完整
- 转入时的课程差距
- 是否需要额外语言、數學或學術補強

#### 中学至大学

- DP课程和科目组合
- 評估方式
- 香港和海外大学申请要求
- 文书、活動、預測成績和申请时间线

#### 主产品

- IB学校报告
- IB课程衔接比较
- IB学校筛选
- IB家庭执行成本评估
- IB大学地区出口指南

### 6.3 A-Level 路线

#### 幼稚園至小学

- 英文閱讀和數學基礎
- 国际/英文学校选择
- 未来 IGCSE 衔接条件

#### 小学至中学

- IGCSE、O Level或其他中学阶段资格
- 学校是否提供完整 AS/A-Level
- 学科组合和转校窗口

#### 中学至大学

- AS/A-Level科目选择
- 香港、英国和其他地区申请方式
- 成绩、预测成绩、文书和截止日期
- 学费、考試和海外申请总成本

#### 主产品

- A-Level学校报告
- IGCSE/A-Level课程比较
- 选科规划
- 英国及海外大学路线指南

## 7. 现有网站资产如何复用

### 已有资产

- 幼稚園及小学深度报告
- P1自行分配和统一派位工具
- 学校比较
- 收藏系统
- 家长问题摘要
- 申请与到访时间线
- 资料来源和核验面板

### 第一阶段应接入路线工作台

```text
路线卡
  → 当前阶段
    → 推荐学校报告
    → 收藏
    → 两校比较
    → P1模拟器
    → 行动时间线
```

### 当前主要缺口

- 中学学校数据库
- 中学课程和选科数据
- DSE/IB/A-Level学校级课程核验
- 大学出口数据库
- 家庭规划档案
- 路线年度复评机制

## 8. 信息架构

```text
/cn/planning
├── 开始规划
├── 当前阶段
├── DSE路线
├── IB路线
├── A-Level路线
├── 尚未决定
├── 学校与课程数据库
├── 学校比较
├── 我的收藏
├── 我的规划
└── 资料来源与方法论
```

首页主入口建议改为：

> 开始规划孩子的教育路线

而不是只把「深度报告」作为第一入口。

## 9. 产品分层和商业化

### 免费层

- 路线基础说明
- 路线选择器
- 公开学校搜索
- 基础学校比较
- 收藏
- 部分P1工具
- 官方制度和时间线

### 单次付费层

- 单校深度报告
- 两校对比报告
- P1完整体检报告
- DSE/IB/A-Level路线报告
- 课程选择报告

### 会员层

建议最终形成：

> **家庭教育规划会员**

包括：

- 一个或多个孩子档案
- 路线图
- 学校收藏和比较
- 年度数据更新
- 时间线提醒
- 路线复评
- 报告折扣或组合解锁

### 高价服务

- 路线选择人工复核
- 中学 shortlist 审核
- P1志愿表复核
- DSE/IB/A-Level路线咨询

## 10. 数据和可信度设计

所有学校、课程、时间和出口资料都应具备：

```text
academic_year
source_url
source_type
last_verified
confidence
change_note
applies_to
```

并区分：

- 官方事实
- 学校公开资料
- 多源交叉资料
- 家长经验
- 平台分析
- 未核实推断

路线建议要能够解释：

> 为什么推荐？依据是什么？哪些资料仍然不足？

## 11. 开发路线图

### Phase 0：产品骨架

交付：

- `/cn/planning` 路由
- 规划入口
- 当前阶段选择
- DSE/IB/A-Level/未决定四张路线卡
- 家庭规划资料模型

验收：

- 用户 3 分钟内可得到路线卡
- 能看到当前阶段和下一步
- 不修改现有报告 JSON和付费授权逻辑

### Phase 1：先完成幼小纵向闭环

```text
K3
→ 幼稚園报告
→ 小一计分/自行分配
→ 统一派位模拟器
→ 收藏和比较
→ 时间线和叩门后手
```

验收：

- 路线工作台能直接打开现有产品
- 收藏学校可以回填比较和模拟器
- 时间线显示学年、来源和核验状态

### Phase 2：建设第一批中学资料

优先覆盖：

- 主要直资一条龙学校
- 热门 DSE中学
- 具备完整 IB衔接的学校
- 具备 IGCSE/A-Level 的学校

每所学校至少完成：

1. 招生机制
2. 课程阶段
3. 选科/科目
4. 学费与执行成本
5. 語言環境
6. 升學出口
7. 支援和轉校
8. 官方来源和核验日期

### Phase 3：三条路线产品化

- DSE路线报告
- IB路线报告
- A-Level路线报告
- 三路线比较
- 中学课程筛选
- 选科规划

### Phase 4：大学出口和年度复购

- JUPAS/本地大学资料
- 海外主要申请地区
- 课程认可和申请渠道
- 年度路线复评
- 资料变更提醒
- 家庭会员

## 12. 当前不应优先做的事情

- 不要一开始覆盖全部香港中学
- 不要一开始建设完整全球大学排名
- 不要把职业教育做成独立重型产品
- 不要用一次测试决定孩子未来路线
- 不要在资料不完整时给出学校或路线排名
- 不要把国际课程标签自动化推断
- 不要承诺录取概率或大学录取结果

## 13. 核心指标

### 用户价值

- 路线选择完成率
- 规划工作台完成率
- 收藏学校数量
- 学校比较使用率
- 时间线待办完成率
- 路线复评回访率

### 产品转化

- 路线卡到学校报告点击率
- 路线卡到工具启动率
- 报告购买率
- 会员转化率
- 规划服务咨询率

### 数据质量

- 有核验日期的学校/课程比例
- 过期资料发现时间
- 用户纠错率
- 官方来源覆盖率
- 课程标签纠错率

## 14. 最终建议

港学荟不应做成「所有升学内容的百科」，而应做成：

> **围绕 DSE、IB、A-Level 三条主线，把孩子从当前阶段带到下一次关键决策的教育规划工作台。**

第一版最值得做的是：

1. `/cn/planning` 路线入口
2. 家庭规划档案
3. DSE/IB/A-Level/未决定路线卡
4. K3→小一→小学的真实纵向闭环
5. 明确显示中学资料建设状态

其他出口保留为「备用路线」模块，不在第一阶段抢占数据和开发资源。
