# 幼稚园名录样板：本地验收

2026-10-26。状态：样板版面已获用户确认；没有部署或推送。后续班制、语言和学费核对见 `kindergarten-fields-2026-10-26/README.md`。

## 已实现

- 现有 958 所幼稚园全部保留，桌面使用紧凑表格，手机使用键值清单。
- 校名／英文名／社区／地址搜索，地区多选，办学性质、明确班制、PN记录、课程、语言记录和已有报告筛选。
- 表头及菜单排序、可选栏目、原生 HTML 分页、筛选结果分页；搜索参数可分享、刷新和返回恢复，简繁切换保留参数。
- 展开查看完整记录、年份和来源；2–4 所幼稚园同栏比较；保存到现有本机候选清单。
- 候选清单中指向资料页的链接改为“查看学校资料”；幼稚园的后续入口返回幼稚园名录，不再误送到以小学数据为主的比较器。
- 仅幼稚园名录使用紧凑页头。小学、中学继续使用原有名录布局。

## 数据边界

这不是对 958 所学校完成新一轮逐校研究的声明。样板从现有已带来源的资料中提取结构化字段，并保留完整文字；不确定项不参与肯定／否定条件的判断。

样板提取阶段有明确班制记录的 319 所、可归入所列语言标签的 372 所；PN有记录446所、来源列未提供22所，其余待确认。PN包括2025年9月的观察记录，界面明确标日期，不等同当届服务或学位。多校址学校的差异在样板中保守处理为“按校址查看”，不跨校址组合语言、班制和PN。

样板确认后，还需把更多学校原始资料中的班制、语言和费用转成可比较字段；金额排序、预算筛选和全量教育计划筛选尚未启用。
