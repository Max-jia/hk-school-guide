# 首批 50 所中學報告：本地上線驗收記錄

**驗收日期：** 2026-10-20（香港時間）<br>
**範圍：** 凍結名單中的 50 份中學報告、各自繁簡頁及中學報告列表；本記錄不代表已部署到公開網站。

> **版式驗收更正：** 本文件較早的「可上線」判斷漏核了線上新版報告的實際版式。當時只有 6/50 所中學啟用新版渲染，其餘 44 所仍走舊版；原判斷在版式方面無效。下方「線上新版版式複驗」記錄修正後的結果，發布時應以該節為準。

## 發布判斷

本批報告的**本地內容呈現與技術門檻通過**。報告均有來源登記、逐校斷言帳本及內容審計；當屆未公布的學額、收費、考試分母和最終去向，仍以「未公開／待確認」或歷史年度標示，不用猜值補齊。可把這 50 份作為一批待發布內容準備部署；正式部署前須按發布當日再掃描會變動的申請入口和截止日。

這個判斷以已有的逐校核對記錄、10 月 20 日的高時效官方頁增量複核，以及本次整批頁面驗收為基礎，**不等於 2,424 條矩陣斷言今天全部重新打開原件核對**。統一矩陣本身是索引，不是重新核源證明。任何尚未由校方提供的資料或校方原件互相矛盾的內容仍是發布後的追蹤項，不能轉述為確定數字。

## 整批門檻及證據

- 凍結名單 50/50 份 JSON、50/50 份 claim ledger、50/50 份逐校內容審計；50/50 均在網站中學報告列表可找到。
- 報告規則檢查：50 份，0 份不通過、0 條提醒。`npm run audit:report-sources`：全站 81 份報告／162 個繁簡頁的可見來源連結與 JSON-LD 引用一致。這項檢查核連結對照，**不證明校方網站永久可訪或每條原文仍未更新**。
- TypeScript、`git diff --check`、Next.js 16.3.0 的 webpack 生產構建通過；生成 675 個靜態頁面。定向 ESLint 0 錯誤，報告列表有 1 條既有 `img` 效能提醒，指向仍使用舊 SVG 封面的幼稚園／小學卡片，與本批中學文字封面無關。
- 50 校繁體及簡體共 100 個正式構建的本地路由，在 390×844 CSS px 實頁檢查：HTTP 200、章節存在、無頁面級橫向溢出、超寬表格均可在自身捲動區移到末列、JavaScript 頁面錯誤 0。這次初驗**沒有檢查全部報告是否採用線上新版版式**，不能單憑此項支持可上線結論；新版複驗見下。

## 仍須按來源原貌保留的邊界

- 統一矩陣有 2,424 條斷言行；本輪重建後機器歸類仍有 20 條來源／口徑差異、40 條未公布／待確認，另有 954 條因帳本欄位格式而無法自動識別狀態。`954` **不等於** 954 條已證實錯誤，也不能當成 954 條已獨立核實。具體結論須回到逐校帳本和原件；矩陣不能單獨充當發布簽核。
- 可見的校方原件差異包括哈羅考試頁兩種百分比口徑、墨爾文同學年兩個擬定費額、培基舊概覽 5／6 班差異，以及其他學校的版本／單位差異。報告按較新或更直接的原件表述並揭示矛盾，**不挑一個未獲確認的數字當最終事實**。培基申請門戶舊日期問題已於 10 月 20 日由校方頁面更新消除；矩陣保留舊版追溯說明。
- 中學統一評級方法尚未通過跨學制可重算校準；報告維持「暫不評級」，不以小學等級或臨時分數代替。這是[現行方法研究](secondary-rating-method-v2-proposal-2026-10-19.md)的資料邊界。
- 官方招生、費用及成績頁可能在發布日更新。部署當日應重新打開有正在申請或即將截止的官方入口，若出現新的校方數字、期限或文件，就先修正報告再發布。這是時間敏感內容的發布檢查，不要求捏造仍未公布的學額、分母或正式價目。

**部署狀態：** 尚未部署；本文件只記錄本地驗收與可發布範圍。

## 線上新版版式複驗（更正先前漏項）

- 根因：`usesEditorialReportLayout` 原本依賴固定名單，50 所中學只有 6 所在名單中。現直接以本批 `SS_REPORTS` 50 校索引啟用同一渲染，避免新增中學報告時重複漏列。
- 以 [線上 DGJS 新版報告](https://hkschool.guide/reports/dgjs) 的實頁對照：現有中學報告在手機和桌面均使用相同的 editorial 首屏、資料帶、目錄、章節分欄、表格與來源區。中學按事實邊界顯示「暫不評級」，不借用小學評級。
- 最終獨立包再次完成 Next.js 16.3.0 webpack 生產構建及 TypeScript，生成 **620** 個靜態頁面。解析 50 校 × 繁簡 = **100 個構建 HTML**：新版外框、資料帶、目錄、至少 8 個章節、章節分欄、表格捲動容器和可見來源區均存在，**0 個缺項**。
- 使用實際瀏覽器逐頁打開 **100 個繁簡頁的 390 CSS px 手機視口**及 **100 個繁簡頁的 1280 CSS px 桌面視口**：新版標記、至少 2 個資料欄、章節、目錄、表格、來源區均存在，**0 個頁面級橫向溢出或結構缺項**。這是逐頁 DOM／尺寸核查；目視樣本包括培基、啓思及線上 DGJS 的首屏，以及啓思第一章表格，並非聲稱人工逐屏閱讀了 50 份全文。
- 啓思原稿的無類別表格已在新版容器內顯示；抽查一張四欄表時，容器約 385 px、表格約 620 px，`overflow-x: auto`，表格字級 13 px、儲存格內距 10×12 px。新版啓思頁面實際點擊 PDF 後在本機下載目錄取得 **11 頁、3,070,076 bytes** 的 PDF；瀏覽器下載事件等待逾時，但檔案格式與頁數已從產物確認。
- 本次修正只處理版式及資料帶來源，不重新聲稱所有 2,424 條斷言已在今天逐條重開原件。仍須遵守上方發布當日的高時效資料複核邊界；本分支尚未推送或部署。
