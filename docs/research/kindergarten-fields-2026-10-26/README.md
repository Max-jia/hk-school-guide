# 幼稚园班制、教学语言、学费核对

2026-10-26。本地验收完成；用户已授权提交及生产发布，部署结果另存发布记录。保留用户已确认的名录版面，新增资料由名录与简明资料页共用。

## 本轮范围及结果

核对名录中958所幼稚园、989个登记校址。学校编号为6位，校址编号为4位；不会把同一机构不同学校编号、不同登记校址或PN与K1资料混用。

| 项目 | 结果及边界 |
|---|---|
| 班制 | 950所可用共同登记时段概括；3所需分校址展示；5所沿用既有停办历史说明，不将历史登记当作重新招生。 |
| 学费 | 893所学校层面记录含明确年费金额；不代表所有校址、所有班别或所有资助资格均同价。另有分校址、课程限定、审核中及未核实记录，见逐校清单。 |
| 费用状态 | numeric 889；scope-specific 17；program-specific 1；pending 7；unresolved 39；停办历史5。上述状态与金额覆盖统计不是同一指标。 |
| 语言 | 记录明确授课语言、班型、中英教师协作、语言课程／活动或语言目标；仅有语言活动不产生“以英语为主”等标签。428所仍未取得足够明确的主要语言说明，另有其他学校已能说明活动但仍不能判断主次。 |
| 授课语言筛选 | 只有18所记录满足明确且适用范围一致的语言／班型条件；这是本轮证据充分的记录数，不是香港只有18所使用这些语言，也不是学校质量排名。旧字段标签未能在本轮原文确认的，不继续当作明确主语言。 |

## 查阅的资料

- 教育局公开位置CSV与每日注册XML，2026-10-26读取；保存SHA-256及逐校址原始时段。两份数据有差异时列明差异，不从金额或师生比例推断班制。
- 现行2026/27概览读取成功925个校址页；应用时只接受与当前登记校号及校址匹配的条目。另81个候选页无法验证相同身份，包含旧校址及未取得当届概览的校址，不据此认定学校不存在。
- 936所学校已记录的官网／课程入口逐一尝试读取，611个页面成功取得，其他访问、证书、路径等失败记入审计。只用内容和身份／范围足以支持的资料；成功读取不等于已确认主要语言。
- 4个中文版明确写“没有中文资料”的概览另查官方英文版；另114个中文版列“没有资料”，不把这项缺失改写成学校没有语文教学，也不补写主语言。另对德萃官网中文页、国英招生页作补充人工查阅。
- 共读取86份教育局收费证，用于概览缺项、待审核、迁址、课程／年级复杂或已发现差异的学校。分段保留生效日期；不把旧收费段统一改成2026/27。

## 重要处理

- 德萃红磡604445及马鞍山616290：收费证已列2026-09-01生效半日K1–K3全年76,780元，11期；覆盖概览的审核中状态。官网说明每班由英语教师和普通话或广东话教师协作，不能由教师数量推算语言百分比。
- 民生鲗鱼涌630640：只用该校址2026-09-17生效证书，不套用官网2025/26其他校舍价目。
- 国英九龙塘215120：K1与K2/K3费用、上下午班及2027/28英粤／英普招生分开；红磡586625的PN不并入九龙塘。
- 安基司565199：富莱花园与涤涛山全日年费分别105,600及106,700元，按校址列明。收费证存在不消除概览“没有开办全日班”的差异提醒。
- 空格／“-”不当免费；价格区间同时保留两端金额及各自期数；澳洲学校自然年、Kellett Reception及AIS Early Childhood不强行改成本地K1–K3。
- 新核对费用取代旧的同标签简称；保留原有课程、师资、设施及有独立信息的限定说明。报告正文和小学／中学资料不改。

## 证据文件

- `registry-sessions.json`：两份教育局数据的逐校址时段、地址及原始文件摘要。
- `overview-source-cells.json`：保留空格的收费格、注册费文字、幼儿服务日期、语言相关句子、校址身份及原网页SHA-256。
- `official-language-passages.json`：官网访问结果、身份匹配及待审语言原文。
- `english-overview-checks.json`：4个英文版概览的补查记录。
- `fee-certificate-ledger.json`：86份收费证来源、生效日期及SHA-256。人工核准取值在`src/content/kindergarten-field-manual-reviews-2026-10-26.json`。
- `school-field-ledger.csv`：958所学校三项字段、状态、日期和来源，UTF-8 BOM，可用Excel查看。
- `coverage.json`、`built-profile-check.json`、`browser-checks.json`及`preview/`：覆盖和验收证据。
- 上一级`kindergarten-official-field-source-audit-2026-10-26.json`保留61项命名差异／收费与开班差异，属于需注明的来源差异，不是61个未处理的渲染错误。

## 验收

- 20项数据与筛选验收通过，包括跨校址、PN/K1、空格、价格区间、旧证书、语言活动与实际授课的边界。
- 生产构建5146页通过；1916个幼稚园简繁资料页均有更新区块和对应来源链接。
- 全站SEO/GEO检查通过，4386资料页、228报告、5122 sitemap URL及三学段覆盖保留。
- 浏览器抽查简繁名录、语言筛选、简繁参数保持、375像素手机、768像素平板、1440像素桌面；德萃资料一致、国英年级费用及PN界限、安基司两校址价差和开班差异提醒。没有页面水平溢出；最终预览无浏览器错误。
- 浏览器是代表页抽查，不声称逐个手动看过958所学校的每个视口。原有无关CSV换行差异保留。
