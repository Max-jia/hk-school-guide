# 第24批父代理：孙方中小学

核对日2026-10-28。只以实际读到的教育局及学校原件刷新本校关键事实。

## 修改

- 2026/27核准24班、2025/26教师49/核准46，教龄49%超过10年；原班师比和由其推断同堂教师配置撤去。
- 免学费不等于全部免费：家教会50、非标准450另列；不把创校1987等同整栋校舍当前楼龄。
- 课程正式写普通话与英语；中文中普结合，英语有Space Town及KEYS2；撤去数学常识必用粤语／全校全普通话／NET每日授课等无课时证据断言。
- 一条龙关系已确认；按官方机制解释，不把它转为12年没有学习压力、大学保证或个人升读概率。旧微信40%三大、80%八大与数据库Band1B无原始分母支持，移除其回报依据。
- 已找到2025/26官方志愿结果表，纠正从未公开结果的表述；89/4/4/3%，加总前三约97但没有分母，不能算Band1率或倒算人数。
- 最新2027/28招生原件和EDB日程交叉；50是自行配额，不是统一派位余位。保留原正确的八项计分说明，更新申请策略。
- 常设插班页文件/30元/约两周结果已核；不继续猜每年4–6月、小二至小五均开放、固定中英数考题。
- 历史家长意见保留主题与年代；未核实的多帖合成长段匿名对话改为访校问题，不伪装新访谈。

## 边界

逐班实际学生人数、完整语言时数、实时插班空缺、原帖样本身份与数量、本校每届一条龙实际升读人数及中学DSE/大学分母仍未取得。其他比较学校2019旧数据不升级为2026新证据。

## 追加修正第23批
