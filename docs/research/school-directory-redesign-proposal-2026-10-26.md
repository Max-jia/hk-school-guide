# 港学荟学校名录改版方案

日期：2026-10-26。状态：待用户确认，尚未修改网站页面或发布。

## 1. 改版方向

桌面以紧凑、可排序的对照表为主，手机以字段顺序一致的学校清单为主。围绕家长的实际流程组织：设定条件 → 缩小名单 → 横向比较 → 保存候选 → 查资料或读报告。

借鉴升学天地的统一栏目、逐列比较和按学段组织资料，进一步补足教学语言、真实费用、校址差异、筛选状态保存和候选比较。继续沿用港学荟现有品牌、简繁切换和三学段导航。

布局示意：[桌面与手机示意图](school-directory-layout-proposal-2026-10-26.png)。图中学校和数值为明确标注的布局示例，不作为学校事实。

## 2. 本次核对范围与现状

- 阅读用户提供的三张截图，并打开升学天地幼稚园、小学、中学名录原页面；实际查看其幼稚园表格、筛选、分页和手机布局。
- 浏览港学荟线上三个学段名录，实测幼稚园搜索；核对当前发布代码中的名录组件、学校数据模型、分页、候选及比较功能。
- 用 ui-ux-pro-max 检查表格、搜索、响应式和无结果状态。工具通用输出中的儿童游戏字体不适合家长决策工具，不采用；保留本站中文字体与成熟的视觉风格。
- 对当前工作树解析后的 2,193 个学校资料条目做字段存在性盘点。它与本轮已发布应用的名录代码对应；盘点不代表逐字段重新查证。

| 当前问题 | 家长的实际障碍 | 改版回应 |
|---|---|---|
| 三列卡片中反复出现英文名、地址、长费用段落 | 看很多字，仍很难横向比较 | 桌面统一表格；英文名、详细地址移入展开内容 |
| 三个学段都只有关键词、地区、类型筛选 | 不能按 PN、时段、校网、升学关系快速缩小范围 | 按学段提供不同筛选字段 |
| 搜索使用本地状态，实测搜索后 URL 不变 | 难以分享同一组条件；刷新、返回或切换语言不能可靠恢复 | 将筛选与排序状态写入 URL，恢复返回位置 |
| “显示更多”和原生分页并存 | 用户不易理解当前浏览范围 | 明确分页为主；筛选结果同样有清楚的范围和翻页 |
| 幼稚园已把办学性质与课程写明，但混在同一个类型筛选选项内 | 难以表达“非牟利且提供非本地课程”这种组合 | 办学性质、课程、资助分别筛选 |
| 中学卡片直接截取语言政策长文 | 宣传活动与实际授课语言混杂 | 整理初中授课语言摘要，保留原文供核对 |
| 有学校多校址、跨区 | 学校层面的单一费用或语言值可能误导 | 标示多校址，并按具体校址展示差异 |

升学天地的优势是表格字段一致且能逐列排序。但它的幼稚园“Free”表示参加计划，不能直接理解为家庭学费为零；“规模”是课室总容量，不能直接理解为当届招生人数。我们的默认列表应优先展示家长会据此做选择的字段。

- 名录结果占页面主要宽度，不设占据约三分之一宽度的常驻文章侧栏。攻略放在结果下方，避免压缩表格。
- 页头压缩为标题、数量、简短说明。详细统计、资料边界放到底部或“资料说明”展开区。
- 正常浏览时桌面固定表头；学校名称列在需要横向滚动时固定。不能遮住导航、焦点或学校操作。
- 保留现有 50 条的基础分页及可抓取路径。首版保持一个分页体系，暂不增加 10/25/100 条等额外分页组合。
- 提供“显示栏目”调节次要字段，默认列保持稳定。不是把每个数据字段都塞进首屏。

## 4. 三学段栏目与筛选

### 幼稚园

**默认表格**：学校及地区、办学性质、上课时段、PN、教学语言、学费、资料入口；另有勾选候选的窄列。

| 项目 | 推荐展示方式 | 重要边界 |
|---|---|---|
| 学校及地区 | 中文校名；第二行列地区／社区；多校址提示 | 不能把不同学校编号的同品牌分校随意合并 |
| 办学性质 | 非牟利／私立独立／待核实 | 国际或非本地课程单独标注，不与非牟利互斥 |
| 上课时段 | 上午／下午／全日／长全日 | 同校不同班别、校址及年份分别记录 |
| PN | 有／无／待确认，并解释为约 2–3 岁服务 | 不根据校名“幼儿园”推断；Nursery 不一律等于 PN |
| 教学语言 | 如“粤语为主”“英普班／英粤班” | 只依据明确来源；“两文三语”不能自动归类为主语言 |
| 学费 | 学年 + 班别 + 年费；注明资助后及资格条件 | 参加教育计划不等于免费；PN 与 K1 收费分别显示 |
| 资料入口 | 学校资料；有报告才显示深度报告入口 | 未有报告不占一行反复写“暂无深度报告” |

常用筛选：地区、办学性质、上课时段、PN。

更多筛选：本地／非本地／两类课程、主要授课语言、参加教育计划、半日班学费为零、年费区间、已有深度报告、办学团体。所有筛选只在数据口径具备条件后启用。

展开行：完整地址与校址、中文采用粤语／普通话情况、英语的日常授课或专科安排、校车、师生比、费用与来源。课室容量和在校人数放这里，并附统计日期，不作为默认招生规模排序。

### 小学

**默认表格**：学校及地区、办学类别、小一校网、性别、教学语言、升中关系、学费、资料入口；另有候选勾选列。

- 常用筛选：地区、小一校网、官立／资助／直资／私立、性别。
- 更多筛选：课程、授课语言、中文科粤语／普通话、直属／联系／一条龙关系、费用、宗教、已有报告；国际与英基按现有分类及来源提供清楚入口。
- 升中关系显示“关系类型 + 目标中学校名”，不能只写含糊的“有中学”，也不把关系写成直升承诺。
- 公营学校小一校网、学校所在行政区分别显示。私立、直资或国际校若不适用该派位校网，应写“不适用”，不能根据地址补一个校网。
- 展开行提供校车、入学途径、中文科授课安排、升中条件与原始来源。师生比、每班教师数不是同一指标，分别保留名称。

### 中学

**默认表格**：学校及地区、办学类别、参考定位、初中授课语言、课程路线、性别、学费、资料入口；另有候选勾选列。

- 常用筛选：地区、办学类别、参考 Band、初中授课语言。
- 更多筛选：DSE／IB／A-Level 等实际开办路线、性别、费用、宗教、升中关系、寄宿、已有报告。
- “参考定位”可以显示已审核报告中的 Band 1A／1B 等判断，字段旁明确“参考·非官方”；保留依据、年份和判断范围。其他学校显示“资料不足”；国际课程学校显示“不适用”，不硬套本地 Band。
- 中学的 Band 参考、平台综合评级和学生派位组别是不同概念。不能从英语授课、校名、地区或单年成绩直接推导 Band。
- 语言默认列强调中一／初中实际授课安排；按科或按班分流的，摘要要保留该限制。展开行再列高中、具体科目和英语支援，不能由“聘有外籍教师”推断为英中。
- 默认不按 Band 或 DSE 单一指标从高到低排名。成绩跨年、分母和课程不同，不宜做混合排行榜。

## 5. 交互：比对方多解决几步选择问题

1. **组合筛选**：同字段多选取并集，不同字段取交集；当前条件以可删除标签呈现。地区多选方便跨区通勤家庭。
2. **模糊搜索**：同时支持简繁、英文名、已核实简称、社区和校址；别名须有映射，不做无边界猜测。
3. **结果可解释**：显示符合数量、当前范围和排序。多校址学校说明为何命中；详细字段应取匹配校址，不能取另一校址的数据。
4. **排序**：默认稳定的校名顺序；主动搜索时优先精确校名和已核实别名。地区、同年度同班别学费可排序；费用不可比或未知的放末尾，不按文本里的第一个数字排序。
5. **逐行展开**：保留首屏简洁，想深入时再展开。学校名仍是正常链接，支持新标签打开。
6. **候选与比较**：先选 2–4 所同学段学校，保存到现有“我的候选”，并做同字段对照。比较中保留未知值和来源，不把空白补成否或零。
7. **状态保存**：筛选与排序 URL 可分享；进入资料页后返回，恢复筛选、页码和位置；简繁切换保留条件。候选首版沿用本机保存，清楚说明不会自动跨设备同步。
8. **无结果处理**：说明当前条件没有匹配，提供删除某项条件、查看数据尚未确认学校的选择。不能悄悄放宽条件后仍声称符合。

通勤先以地区／社区、校址与校车资料协助判断。地图距离、通勤分钟和“附近学校”留待坐标与交通方案具备条件后再做；不由行政区估算行程。招生状态及截止日期也只在有当届原始公告并能持续维护时上线。“热门学校”若将来加入，须用真实时段内浏览数据，并说明它不代表学校质量。

现有候选模块支持三学段，但现有比较模块主要使用小学数据，并不是 2,193 所资料页通用比较器。需要让比较页接入统一学校标识及资料模型，不能只在名录增加一个按钮就宣称三学段比较完成。现有按名称生成的候选 ID 也要考虑学校编号、学段和校址，兼容原有候选记录。

## 6. 手机设计

- 手机默认切换为紧凑清单，不压缩一张八九列的桌面表格。
- 校名可换行，下方固定顺序展示地区与类别、语言与时段、关键费用；剩余字段点开查看。
- 顶部保留搜索和“筛选（已选数量）”“排序”。完整筛选放抽屉，先编辑，点“查看 N 所学校”后应用，避免每勾选一项就打断操作。
- 底部只在选校后出现候选操作条，预留安全空间，避免挡住最后一行。
- 需要精细比较时进入专门比较界面；可横向滚动，但固定指标名，并提示左右滚动。常规名录不要求反复横向拖动。
- 学校名称 16px 起、辅助资料至少 14px；触控目标至少 44px；不靠颜色或悬停解释字段，键盘与读屏都能使用。

## 7. 数据准备：先整理，再让筛选器作判断

当前解析后条目：幼稚园 958、小学 648、中学 587，合计 2,193。数量按本站学校编号和学段归并口径，包含不同类型学校，不直接与升学天地的表格行数作“谁更齐全”结论。

| 学段 | 现有顶层字段存在情况 | 对实施的意义 |
|---|---|---|
| 幼稚园 | 课程类型 911；语言 894；费用 898 | 原始文字较多，须转为按校址、班别和年份记录的结构化值 |
| 小学 | 校网 603；语言 482；费用 549 | 需要区分有效校网、不适用与待核实，不能直接将非空值当作可筛选的正确值 |
| 中学 | 语言 441；费用 60 | 语言可从原始政策精炼；不能把没有费用文本的学校直接当成免费 |

上述是非空字段数，不是已核实覆盖率。部分内容只写“待确认”，部分详细字段在子区块，不在顶层；不能用这个盘点代替内容验收。

数据实施标准：

- 每个供筛选或排序的字段保存值、状态、适用学年、校址／年级／班别和原始来源。
- 布尔项至少区分是、否、未知；另需“不适用”。未查到不等于不存在。
- 学费同时保留原文与结构化金额、币种、期数、班别、年级、资助口径及额外费用边界；不可比时不参与金额排序。
- 语言把“中文科授课语言”“其他科目教学语言”“英语课／日常语言环境”分开，不能统统归为两文三语。
- 涉及班别、校址相互冲突的值，列表显示“各校址有别”并引导选择，不能合成一个虚假的学校统一值。
- 旧资料仍可在详情说明学年，但不与最新费用混排为当前报价。
- 单独提供“资料待确认”筛选或计数，让家长知道筛选覆盖的边界。
- 实施时输出逐字段覆盖审计；待确认比例较高的功能推迟启用，而不是靠生成式推断补齐。

## 8. SEO 与现有页面衔接

- 保留现有学校资料、报告和名录分页路径，不因视觉改版改变学校身份或制造失效链接。
- 名录每页仍以服务端 HTML 提供实际学校链接和分页链接；不能把结果全部换成搜索后才生成的表格。关闭 JavaScript 仍能浏览基本名录和下一页。
- 普通多条件筛选 URL 用于分享和恢复，不批量制造可索引的参数组合。应明确抓取与索引策略，而不是把所有筛选页 canonical 到首页就算完成。
- 值得长期搜索的地区、校网和类别可逐步做独立集合页，要求有真实需求、足够学校和有用说明，不批量生成重复薄页。
- 保留简繁 canonical／hreflang、CollectionPage／ItemList、School 实体链接、资料来源；结构化数据必须与当页实际结果一致。
- 本次改版主要改善查找、比较和资料发现；是否提高曝光或点击，需要上线后按页面类型观察，不能预先承诺。

## 9. 实施顺序与确认节点

| 批次 | 产物 | 通过条件 |
|---|---|---|
| 1：幼稚园样板 | 数据字段规范、桌面表格、手机清单、搜索／地区／性质／PN／时段筛选、费用与语言摘要、逐行展开、候选入口 | 使用有明确来源的一组学校验证视觉与数据；其余未知值明确显示；用户确认样板 |
| 2：幼稚园全量与小学 | 全量字段整理、同框架幼稚园名录、小学校网／性别／语言／升中关系；统一候选及同学段比较 | 分字段覆盖清单与记录级抽查通过，再验收两学段桌面／手机、简繁 |
| 3：中学 | 参考 Band 数据接入、初中语言摘要、课程路线与费用；同学段比较 | Band 每条可追溯；国际路线明确不适用；复核复杂语言与多课程学校 |
| 4：搜索入口与效果复盘 | 有价值的地区／校网集合页；名录使用与内容发现指标 | 依据真实使用数据排序后续工作，不以新增页数当成效果 |

所有学段沿用同一版面框架，各自使用适合该学段的字段。第一批确认后再扩展，不先把未经认可的版面铺满三学段。

## 10. 验收标准

**数据**：逐校核对样板的 PN、时段、语言、学费、校网与升学关系；包含多校址、跨区、未知值、国际课程、不适用、旧费用等边界。筛选结果与详情来源一致；组合条件在同一适用校址成立。

**行为**：搜索简繁和别名；多个筛选交集；排序；移除条件；无结果；第 2 页后筛选；分享 URL；刷新与浏览器返回；简繁切换；候选跨页保存；比较不串学段。不能筛到空结果后悄悄丢弃条件。

**版面**：至少检查 375、390、768、1280、1440px；长校名不丢失、中文不挤压；键盘焦点、读屏表头、筛选抽屉、200% 放大、手机底部操作条不遮内容。

**抓取与回归**：服务端 HTML 中有学校及分页链接；原有 URL 无丢失；资料总量、报告及博客清单不缩水；分页与结构化数据一致。若后续发布，重新核对当时真正线上版本为基线。

**衡量**：在确定分析工具和隐私范围后，记录搜索／筛选使用、零结果率、资料页打开、候选加入和比较使用；上线后按设备、学段与日期比较。首版只设基线，不虚设“曝光翻倍”目标。
