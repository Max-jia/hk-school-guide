# 中学报告排版与文字简洁性审计

审计日期：2026-10-20<br>
样本：圣保罗男女中学（SPCC）深度报告<br>
范围：报告实际渲染、共享报告表格样式及首批 50 份中学报告的结构初筛；下方另附 SPCC 样本的实施和验收记录。

## 结论

可以在**不减少实质内容**的前提下明显改善阅读体验。主要工作不是删掉事实，而是把一段里并列的事实、限制和家庭动作拆开，把表格从“把整段分析塞进单元格”改成易扫描的结构，并只合并真正重复的句子。

SPCC 样本的重点问题集中在少数高密度位置，不是所有内容都需要重写：第 4 章有约 1,220 字的招生规则段落；第 6 章一张住宿表的单格约 523 字；第 3、7 章各有一张横向很宽的多列表格。数字型结果表和学校定位表整体仍适合表格呈现。

## 证据与范围

- SPCC 实际报告 DOM 共检查到 8 章、18 张表和约 120 个段落。段落长度是定位工具，不单独代表文笔或内容质量。
- 约 85 个段落达到 120 字，47 个达到 200 字；最长段落在第 4 章，约 1,220 字。另有第 5 章约 781/658/606 字、第 6 章约 803/565/557/550 字等长段。
- SPCC 第 3 章结果解释表有 7 列；第 7 章校际比较表有 8 列，最长单格约 399 字。第 6 章住宿表只有 3 列，但最长单格约 523 字，说明问题也在于单格承担了太多不同信息。
- 实际浏览器检查视口约为 669 CSS px：没有页面整体横向溢出；18 张表均提供可聚焦的横向滚动区域。第 3 章 7 列表约 1,120 px，第 7 章 8 列表约 1,280 px，需要横向滚动。该检查不是 375–390 px 手机视口，也不是实体触屏验收。
- 共享 CSS 为 5 列起逐步设置 800–1,600 px 的最小表宽；窄屏下部分宽表仍依赖横向滚动。另有字号 13 px、单元格内边距 10×12 px、最小列宽 112 px 等统一规则。
- 对 50 份报告的 HTML 结构初筛发现：19 份报告共有 40 段达到 200 字，8 段达到 300 字；初筛识别出 3 份报告含 5 列以上表格。此扫描只用于排序复核对象，不是逐句内容审查，列数识别也不能代替人工查看实际宽度和单格负荷。

## 不缩水精简的编辑规则

1. **先列信息单元，再改句子。** 为每段标出事实、年份/对象、来源、分母、限制、分析、家庭影响和行动项；改后逐项对照，确认没有信息单元消失。
2. **删重复，不删限定。** 只合并语义完全重复的句子。年份不同、适用对象不同、来源互相矛盾、分母未公开、并非保证等限定，即使重复出现，也要在读者作判断的位置保留。
3. **把并列关系显出来。** 长段优先拆为小标题、清单、时间线或“事实—含义—行动”块；不要把同一事实复制到正文、表格和摘要三处。
4. **按比较任务决定表格。** 数值和短标签适合表格；流程用步骤；条件用清单；多校长文本比较用逐校卡片或每校一行的简短维度，并保留来源/完整解释。
5. **简洁不等于省略。** 允许缩短冗长句、统一重复术语、将相同适用边界集中表达；不把“未公开/待确认”改写成确定结论，不用模糊的“详情见官网”替代具体来源和日期。

## 建议实施顺序

1. 先以 SPCC 第 4 章招生段、第 6 章住宿表、第 3/7 章宽表制作一个版式样本，保留原始信息并生成逐项对照。
2. 复核样本：逐条核对来源链接、学年、对象、数字、分母和不确定性；再看桌面、375–390 px 手机布局及键盘可达性。
3. 样本通过后，用“长段/长单格/宽表”规则扫描其余 49 份报告，按高密度位置分批处理。结构扫描只负责排序，具体内容必须逐份复核。

本轮尚未修改 SPCC 正文、其他学校报告或共享样式，也未完成真实手机及触屏验收。建议下一步先实施并验收 SPCC 版式样本，再决定是否推广到首批 50 校。

## SPCC 样本实施与验收（2026-10-20）

本轮只调整 SPCC 报告内容结构与该报告专属样式，没有改动共享报告排版，也没有推广到其他学校。

- **第 4 章申请说明：** 将原来连续招生长段按一般申请、学校提名计划和才艺计划分组，整理为 3 组、18 个项目。逐句拆分核对后，原 18 项信息均保留，只有归组和呈现顺序变化。
- **第 6 章校舍与住宿：** 把设施、F1 两周体验、长期寄宿、费用、住宿生活、交通及支援改为 8 张资料卡；每张卡分列“已核对资料”和“仍需向学校确认”。保留 2024/25、2025/26、2026/27 等年份边界、金额、79 个床位上限和校方页面口径差异。
- **第 7 章同类学校比较：** 将 SPCC、DBS、DGS、HKUGA College 改为逐校卡片，每校保留 7 个比较字段。
- **第 3 章考试结果摘要：** 将三组指标整理为卡片，包括四届 DSE JUPAS 资格比例及考生人数、四届 IBDP cohort 人数、四届 IBDP 平均分；合计 12 个年度值，并保留“可以说／不能据此说”的解释。完整结果表与其他来源说明仍保留在章节中，卡片用于快速浏览。

### 浏览器验收结果

- 使用本地生产构建预览 `http://127.0.0.1:3103/reports/spcc-secondary`。
- 手机窄屏视口实测 374 CSS px：四组卡片均为单列；卡片自身无横向溢出，页面没有整体横向滚动。
- 平板视口实测 853 CSS px：指标卡三列、学校比较卡两列，宽表保留横向滚动容器。
- 桌面视口实测 1,600 CSS px：指标卡三列、学校比较卡两列；页面没有整体横向溢出。
- 键盘验收：聚焦到宽表滚动区后按右方向键，横向位置从 0 移动；焦点轮廓可见。宽表滚动区具有 `role="region"` 和 `tabindex="0"`。
- 页面 DOM 检查：8 张住宿卡、4 张学校比较卡、3 张指标卡（12 个数值）及 18 个招生项目均已渲染。TypeScript 检查通过；`npx next build --webpack` 生产构建通过，共生成 657 个静态页面。
- 限制：这次用浏览器视口模拟窄屏，没有真实触屏设备；浏览器截图接口输出空白画面，因此布局验收依据实际页面 DOM、计算样式、元素宽度、横向滚动和键盘焦点状态，不声称完成截图视觉复核。

目前 SPCC 样本版式已达到可供用户检查的状态。其余 49 份报告的结构密度初筛已另行完成；这是候选排序，不代表逐校内容、来源或视觉审计通过。详见 [49 校排版密度筛查](secondary-report-density-screen-2026-10-20.md)。
