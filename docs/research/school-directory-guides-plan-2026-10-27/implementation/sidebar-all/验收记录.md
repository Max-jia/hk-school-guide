# Blog 全站相关内链验收

日期：2026-10-27。仅本地实现，未提交、推送或部署。

## 范围与匹配方法

覆盖55篇文章：幼稚园24篇、小学27篇、升中1篇、跨学段3篇；繁简共110个文章页面。共329个推荐链接，92个不同目标（繁简184条可访问地址）。

沿用已确认的升中offer样板：桌面右侧三组内链、窄屏标题下原生折叠模块。样板六个链接、组标题及文案逐字段保持一致，样式文件逐字节保持一致，55篇正文文件均未改动。

每篇文章采用独立人工配置，不用标题关键词自动猜学校，也不按学段取列表前几项。配置位于 `src/lib/blog-related-links.ts`。

- 单校文章：申请、语言、费用或升学指南；对应学校报告或简明资料；本学段名录、规划或工具。
- 同名与校区文章：具体对应学校，明确区分幼稚园与小学、不同校区；不把圣保罗男女附小错配至圣保禄学校。
- 校网、计分与叩门：相关制度指南、专题及校网/计分工具，避免无关学校推荐。
- 幼小、小学升中衔接文章允许跨学段链接，但在分组名称中说明两段关系。
- 停课指南是例外：当前没有其他天气攻略，不强塞无关文章。保留相同视觉组件，列三学段名录与候选清单/规划两个分组，方便查学校联络及班制。
- 侧栏名称、摘要随主题改变，繁简文字及路径通过既有 L / localeHref 统一处理；不用“热门”声称不存在的浏览量。

## 验收结果

1. `node scripts/validate-blog-related-links.mjs --build <build-root> --output <mapping.json>` 通过：55篇配置齐全，无自链接、同模块重复链接、空标签或不存在的静态目标；动态规划页由构建清单及HTTP请求双重核对。
2. 110个繁简页面均包含两个服务端输出的内链模块（桌面/窄屏）及单个H1。链接可在HTML中直接抓取。
3. 全量浏览器渲染110页：逐条对比推荐href与人工清单，全部相符；无横向溢出、缺失模块或多余H1。
4. 16个手机案例：覆盖单校、指南、升中、跨学段、学校资料页及长校名，繁简均通过。原生折叠可用Enter展开，桌面模块在窄屏隐藏。
5. 长校名另验320、768、1023 CSS像素宽度：无页面横向溢出、无链接裁切。
6. 55篇繁体桌面侧栏尺寸复核：最高约705px，在800px视口内可完整展示；无链接横向裁切。
7. 184个繁简推荐地址逐一HTTP验证：均200，真实H1存在，无实际404页面。Next.js序列化的not-found后备模板不作为可见404判断。
8. 实际点击五类入口：攻略、学校报告、学校简明资料、工具、专题，目标路径与页面H1正确。
9. `npm run typecheck`、涉及文件ESLint、`git diff --check` 与隔离目录生产构建通过。
10. 沿用已有 `blog_related_view` / `blog_related_click` 事件及定位属性。此轮未更改统计逻辑，也未声称已经收到GA后台数据或已经提升流量。

- `browser-desktop.json`：110页实际DOM与链接。
- `browser-mobile.json`、`browser-responsive.json`、`browser-sizing.json`：响应式与尺寸检查。
- `browser-clicks.json`：五类链接真实点击落点。

本地预览：`http://127.0.0.1:3339`。例如 `/cn/blog/munsang-kg-search`、`/cn/blog/p1-scoring-guide`、`/cn/blog/secondary-dss-offer-guide`。
