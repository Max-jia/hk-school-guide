# Blog右侧内链样板

日期：2026-10-27。仅为 `secondary-dss-offer-guide` 启用，繁简版本共用。当前是本地预览，没有提交Git或部署。

## 已实现

- 延用网站杏黄色、文字层级与分组编号。三组共6个精选目标：两条相关指南／专题、两份文中学校报告、中学名录与升中规划。
- 宽屏：正文约856 CSS像素、右栏280像素、间距32像素；滚动时右栏保持在24像素处。矮屏取消吸附，避免尾部入口不可达。
- 1200 CSS像素以下：显示原生可展开区域；手机竖排，中等屏幕展开后按三个分组横排。默认收起，可以用键盘Enter操作。
- 使用带href的服务端HTML链接，未依赖客户端脚本才能出现。排除当前文章自链；未生成尚未写成的指南入口。
- 文章源文件与此前验收副本逐字一致。其余文章没有启用模块。
- 新增 `blog_related_view` 和 `blog_related_click`，沿用现有GA发送函数。参数包括文章、位置、目标路径、分组及顺序；原有规划事件保留。
- 展示事件仅在模块至少25%进入视口时记录，同一位置每次挂载记一次；收起的手机区域不被观察，展开后才观察。记录已接入前端，不声明GA后台已经接收或浏览量已经提升。
