# 朗思招生逐項核驗 — 2026-11-19

## 可寫進報告的本屆資料

- **2027/28招生**：官方中英文招生首頁與下載表格均列同一年；現行三校為麗港城、馬鞍山、南昌。首頁只說部分班級仍招生，不能寫某校某級肯定有位。
- **PN與K1年齡**：從本屆招生頁進入的面試圖片寫LN（2–3歲）2025年出生；K1/UN（3–4歲）2024年出生。程序頁另要求LN實際入學首日滿2歲、一般8月開始；晚生日孩子不能只憑出生年保證8月開學。
- **面試日期**：圖片為2026年10月31日，查閱日已過。它說電郵邀請面試；成功獲取錄者於面試後兩週內獲郵寄通知，按指定日期到校註冊。不得外推所有插班/往後面試兩週出結果。下一場日期、面試語言及題型未見公開明文。
- **申請校區**：程序頁每童限申請一校；2027/28表格另可勾選，所選校區滿額後是否考慮其他校區。不是三校分別重複申請，更不是轉介保證取錄。
- **表格選項**：LN2–3、UN3–4、LK4–5、UK5–6；AM/PM/全日；三語（英粵普）或國際（全英）。可同勾AM及PM；UK因課室限制由學校決定上午或下午。這是申請意願，不代表每校每級均開全部選項。
- **插班**：表格可填希望入學日期、曾就讀學校和轉校原因，足以寫可以向校方提出轉入申請。全年各月收生、即時空位、候補次序/有效期均未公布，不可寫「全年保證插班」。
- **文件及報名費**：公開程序列填妥表格、出生證明文件副本、近照、HK$40不退報名費、230×100mm回郵信封及HK$4郵票；網上申請者於面試日交信封。ARN是聯絡用申請編號，不代表取錄。

## 註冊、退學及退款要分開說

目前程序頁連結的三校版退學表未標學年：已註冊新生須在第一期書簿雜費自動轉帳日前一個月交表；在讀生須在離校前最少一個月交表。通知不足須補一個月學費。學費按整月收取，不按出席日數攤分。逾期取消另有行政費，但表中沒有列金額。交表十天仍未獲確認應追問。

此表沒有「提前一個月即退還留位費/預繳款」承諾。家長付款前應取得本屆留位費、書簿雜費扣帳日、取消學位行政費，以及每項已付費用可否退款的書面答覆。不得把通知期寫成退款保證。

通用程序仍列LN2024、K12023出生；本屆應以2027/28申請表及當屆面試圖的2025/2024出生年為準。招生首頁另有四校舊退學表；程序頁已有三校表。舊 /ib-admissions 頁是九龍塘117界限街及2024/25、2025/26資料，不是現三校2027/28招生。

2. **PN升K1**：未在上述公開資料找到保證升班、保留K1學位或重新評估的明文。不能寫PN必直升，也不能寫一定要再考。付款前向所選校區問清是否重評估、是否可選班制/課程、升班留位及通知日期。
