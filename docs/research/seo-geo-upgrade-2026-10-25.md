# 港学荟 SEO / GEO 全站审计与升级记录

日期：2026-10-25（香港时间）。状态：**已完成线上审计与本地第一轮通用修复，未发布；内容研究及效果验证分批推进。**

## 1. 使用的 skill 与判断依据

- `seo`：抓取、索引信号、搜索意图、标题摘要、内链与性能。
- `geo-audit`：按技术、实体标记、内容与可信度、AI 可发现性、平台准备度分工复核。
- `geo-schema`、`geo-content`、`geo-crawlers`、`geo-citability`、`geo-platform-optimizer`：分别做专项检查。

技能提供检查框架，不把其中的行业增长数字、固定段落字数、训练机器人角色或“没有 llms.txt 就有严重问题”等说法当作依据。Google 明确说明 AI Overviews / AI Mode 无额外技术门槛，无须专用 AI 文件或特殊 schema；应优先保障可索引的正文、内部链接、准确来源和良好体验。[Google AI features](https://developers.google.com/search/docs/appearance/ai-features)

本轮不制造 GEO / E-E-A-T 百分制总分。真实品牌权威、收录、外链、AI 引用与流量尚无完整当期测量，不能用模板合规分冒充。

## 3. 历史 GSC 揭示的规律及边界

现有最新一份项目导出覆盖 **2026-09-20 至 10-17**，早于本次三学段名录发布。28 天 Chart 合计 280 次点击、7,996 次曝光，CTR 约 3.50%。页面表中的报告详情页为 199 点击 / 5,382 曝光（3.70%）；博客详情为 73 / 2,351（3.11%）。报告贡献约 71% 的点击，仍是关键入口。页面维度曝光与站点维度曝光口径不同，不相加代替站点总量。

`查询 × 页面` 文件有 470 行、18 次点击、1,427 次曝光，只覆盖可导出的部分查询。查询包含收费、教学语言、申请、校网、升学与评价；不能把全站优化压缩成改几个学校标题，也不能根据这些旧记录断言新资料页“没有效果”。

普遍性方向是：**让每类页面负责一个清楚的家长问题，并把事实页、深度分析、制度攻略连接起来。** 报告默认标题不在本轮再大面积改动，避免用尚未反映新版本的数据反复调题。

## 5. 页面分工与下一批内容

| 页面类型 | 主要回答 | 内容与内链职责 |
| --- | --- | --- |
| 简明资料页 | 学校是谁、在哪、什么类别、公开语言/课程/费用是什么 | 学校身份与字段来源、年度边界；连对应报告与学段入口 |
| 深度报告 | 这些事实对哪类家庭有价值、代价与风险是什么 | 保留八章及专家写法；补关键判断的可点击原始来源；回连资料页 |
| 制度/比较文章 | 家长在当前申请阶段如何行动、怎么比较 | 一个明确问题、制度与学校规定分开、具体动作、备选与来源 |
| 学段/专题入口 | 先看什么、接下来读哪篇、去哪找学校 | 主指南 → 具体问题 → 学校事实/报告，避免只换标签造空专题 |

### 下一批 A：逐校补证据链

228 份报告中，代码检查发现 **147 份既没有显式来源面板条目，也没有正文可点击的外部来源链接**。部分有“官网/教育王国/教育局”等文字来源；这不是认定事实全错，而是追溯路径不足。其中个别仅有纯文本官网地址，仍需改成可核对的具体文件链接。

已生成按历史曝光排序的 [147 份报告研究队列](./seo-geo-source-research-queue-2026-10-25.json)（另有同名 CSV 便于筛选），记录旧窗口，状态均为待研究。优先国际英文、 高主教、真光、维多利亚、迦南等历史入口，再按批次推进：

1. 学费/年度、授课语言、升学结果与分母、申请规则分别寻找原始文件。
2. 基础事实交叉核对；媒体/家长评论保留原帖日期和体验边界，不冒充统计共识。
3. 用“事实 → 家庭意义 → 代价 → 行动”补关键证据，不重排已确认的八章版式。
4. 独立复核事实、语言、重复段落、移动排版后，逐批发布。

不能把资料页的官方来源批量塞入旧报告，就声称已核实整份报告所有判断。

### 下一批 B：中学主题组

现有 6 个专题均偏小学/幼稚园，缺系统的中学制度主指南。先研究当届官方制度，再做以下资料，不能用小学攻略凑一个中学分类：

- 中一申请主指南：自行分配、统一派位、直资/私立校本申请各自流程。
- 学生派位组别与学校非官方 Band1A/B/C 定位的区别。
- DSE、IB、A-Level 路线：学习方式、资格、预算、升学与转换成本。
- 插班：实际年级、窗口、考试和学额边界。

术语首次出现解释定义及家庭选择意义；成绩门槛达标比例不能写成大学录取率。新文章通过事实、专家表述、去 AI 味与重复内容审计后，再加入专题及学段导航。

### 下一批 C：既有博客维护与真实责任归属

49/54 篇博客缺专门的 verifiedAt；不能把发布时间当核验日期。按招生/收费/制度时效优先重核，实质修改才记 updatedAt。9 篇未纳入现有专题不等于无 HTML 入口：博客已用可展开清单呈现全部文章；只在内容匹配时增专题成员，暴雨等实用信息无需强塞入入学专题。

组织署名目前使用真实的港学荟平台，不造专家学历或家长故事。后续如有真实负责人/复核者，可加可验证的署名页和联络路径；第三方报道、公开研究引用应来自真实资料与授权合作，不能自动群发、买背书或制造百科条目。

## 6. GEO 的正确衡量方法

当前 robots 允许公开网页的搜索抓取。OAI-SearchBot 是搜索抓取，GPTBot 是训练抓取，二者控制独立；不为“做 GEO”擅自扩大训练授权。[OpenAI bots](https://platform.openai.com/docs/bots)

未来应固定一组 20 个家长问题，覆盖三学段、制度、学校身份、费用/语言与比较，记录问题、语言、平台、测试日期、回答及真实引用 URL。不要在问题里先给本站链接，再把模型复述算自然命中。

| 指标 | 定义与限制 |
| --- | --- |
| AI 引用覆盖 | 引用本站的测试问题数 / 相同测试集问题总数；分平台记录，不推成市场份额 |
| 引用准确性 | 引用页实际支持对应结论；错学段、旧年度、分母误读单列 |
| 引荐到站 | GA4 中可识别 AI 来源的会话/互动；没有 referrer 的流量无法全部归因 |
| 搜索曝光与点击 | GSC 分目录、学段、繁简、设备、地区、查询意图看同长度窗口 |
| 抓取与索引 | sitemap提交/抓取、URL检查中的 Google 选择 canonical、索引状态；200/构建通过不等于已收录 |
| 家庭行动 | 进入对应报告、查看来源、下载 PDF/咨询等真实行为；新增埋点先约定数据口径 |

Google AI 功能流量包含在 GSC Web 搜索中，不能仅从 GSC 总点击准确拆出 AI Overviews。[Google AI measurement](https://developers.google.com/search/docs/appearance/ai-features#measure-performance)
