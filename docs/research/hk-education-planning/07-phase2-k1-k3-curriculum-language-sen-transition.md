# 香港教育規劃研究｜K1–K3課程、語言、特殊需要支援與小一銜接

> **研究日期：2026-10-09（香港）**
> **研究階段：Phase 2｜幼稚園教育經驗與K3至P1銜接**
> **適用範圍：本地幼稚園及幼稚園暨幼兒中心；聚焦課程政策、語言支援、學前特殊需要服務及銜接安排。**
> **研究限制：本文整理全港制度和官方指引，不是對個別孩子的發展評估、診斷、學校排名或錄取預測。校本課程、實際人手和支援須逐校查證。**

## 1. 結論先行

1. 香港幼稚園教育的官方方向是全人及均衡發展，而非提早完成小學課程。EDB《幼稚園教育課程指引（2017）》提出五項發展目標、六個學習範疇，透過生活化主題、遊戲、探索和校本課程組織學習；它提供共同框架，不是每間學校逐週照抄的單一教案。[S1][S2]
2. **遊戲為本不等於放任或沒有教學。**家長要看教師有沒有清晰學習意圖、觀察和回饋，以及孩子是否有探索、表達、合作和反覆嘗試的機會，而不是只數工作紙或背誦了多少內容。[S1][S2]
3. EDB現行幼稚園「應做和不應做事項」明確提醒學校不要過分側重知識灌輸、不要讓課程過重或過難，並寫明**不應要求幼兒班（Nursery Class）兒童寫字**。這是對學校課程安排的指引，不應被誤說成兒童不能接觸書本、文字或作畫；重點是避免把機械寫字操練當成幼兒教育目標。[S3]
4. 非華語（NCS）支援要分成三層查：入學資訊是否可理解、學校是否有實際中文學習及家校溝通安排、相關校本支援或資源是否落地。EDB為2027/28 K1提供多語文件及家長講座；這不等於每校有相同語言人手或同一教學模式。[S4][S5]
5. 學前特殊需要支援正處於服務模式轉型期。社署校本支援模式在2026年分兩階段試行，至2026年9月共有112所參與KG／KG-cum-CCC；社署2026年8月資料列出計劃於2027年9月起，在全港設有兼收計劃或到校學前康復服務的相關學校推行。這**不等於所有幼稚園、所有兒童都已納入該服務**，家長須查學校名單及孩子的評估／服務資格。[S6]
6. 幼小銜接不是「把K3變成小一」。EDB資料將銜接放在課程、環境、社交關係、情緒及家校協作等面向；2024《小學教育課程指引》亦提醒學生各有適應步伐。家長宜重點練習日常自理、求助和轉換環境，而非只提前操寫字、計算或小學課本。[S7][S8]

## 2. 官方課程框架：家長比較時看甚麼

### 2.1 五項發展目標、六個學習範疇

EDB把幼稚園課程定位為促進幼兒全面和均衡發展，五項發展目標為：

- 品德發展；
- 認知和語言發展；
- 身體發展；
- 情意和群性發展；
- 美感發展。

透過六個學習範疇落實：**體能與健康、語文、幼兒數學、大自然與生活、個人與群體、藝術與創意**。課程包含價值觀與態度、技能、知識三個相連部分，並鼓勵以貼近日常經驗的主題整合學習；不宜只用「英文多不多」「識幾多字」判斷課程質素。[S1]

### 2.2 遊戲、探索與教師教學

將「遊戲為本」操作化，可以觀察：

| 觀察點 | 家長可問／可看 | 不足以單獨證明甚麼 |
|---|---|---|
| 學習目標 | 教師希望孩子在遊戲中學會觀察、比較、溝通、協作或表達甚麼？ | 玩具多、活動熱鬧，不自動等於有完整課程設計 |
| 成人介入 | 教師何時示範、提問、提供詞彙或材料，何時讓孩子自行探索？ | 教師少講話，不一定代表放任；要看其觀察與跟進 |
| 孩子參與 | 孩子是否有選擇、試錯、重做、分享想法的機會？ | 一次公開課或宣傳影片，不能代表每日課堂 |
| 差異支援 | 同一活動能否按能力、語言、感官或行動需要作合理調整？ | 「小班」或「個別照顧」標籤，不能代替具體人手與做法 |
| 學習紀錄 | 教師用甚麼觀察紀錄、作品或家校溝通內容回饋孩子進展？ | 一疊工作紙不等於完整發展評估 |

EDB課程指引設有「評估促進學習與發展」和兒童學習紀錄／作品集相關章節；附錄二亦列出2至6歲兒童發展特徵。這些內容適合幫助家長理解多方面發展，不是K1/K2/K3逐項達標的診斷表。家長可以問學校如何記錄孩子在不同範疇的學習，以及如何把觀察轉化成下一步教學；不要把某一項測驗或作品當作孩子能力的全貌。[S1]

### 2.3 明確的課程紅線與口播邊界

EDB「幼稚園應做和不應做事項」目前包括：課程不應過重或過難、不應只灌輸知識而忽略態度與技能、不應要求幼兒班兒童寫字；教學應採用兒童為本活動、讓幼兒透過遊戲和活動愉快學習，並尊重個別差異。該清單也寫有「以兒童母語作教學媒介」及避免混合語碼教學。[S3]

這些規範性提醒**不能推演成**「所有幼稚園完全不能有書寫、識字、數學活動」或「遊戲時間越長就必定越好」。應核對校本課程、孩子的年齡與發展、教師教學和學習目的。校本課程若有明確的閱讀、語文、數學或英語元素，需問清楚它如何適齡、如何與遊戲和生活經驗連結。

## 3. 語言規劃：先看孩子的語言經驗，再比較學校承諾

### 3.1 不把語言標籤當成能力評估

NCS是教育支援分類，不宜直接等同國籍、種族、中文能力或家長英語能力。EDB的2027/28幼稚園支援頁列有英文、中文、印尼文、印地文、尼泊爾文、印度旁遮普文、他加祿文、泰文、烏爾都文及越南文材料；EDB列明2027/28 K1家長講座日期為2026年7月11日，並提供多語資料及簡報。[S4]

EDB的幼稚園NCS政策資料及2027/28 K1收生簡介提醒學校公平處理不同族裔兒童的申請，並提供中英文申請資料；如NCS兒童面見需要溝通協助，學校須按指引安排傳譯／翻譯，或容許家長與兒童由懂中文的親友陪同。幼稚園概覽亦是查看學校公開NCS支援資訊的入口。[S5][S15]

### 3.2 逐校語言支援核查表

EDB的政策方向鼓勵NCS兒童及早在中文使用較豐富的幼稚園環境學習中文；同時，EDB一般幼稚園指引使用「以兒童母語作教學媒介、避免混合語碼」的措辭。[S3][S5]這兩項指引需要放回個別學校與兒童的語言情境理解：不能推成每所學校都能以每名兒童的家庭語言授課，也不能推成「中文沉浸」對每個孩子必然有相同效果。家長需問清中文接觸時段、教師如何支援初學者、孩子能否參與日常活動，以及學校和家庭如何溝通。這是政策解讀與選校核查問題，不是本研究已證明某一教學模式效果更好。

不要只問「是不是英普／全英／沉浸式」，而要逐項問：

1. **主要教學語言**：中文、英文、普通話各在甚麼時段、由誰使用？語言標籤指課堂媒介、外語活動，還是宣傳描述？
2. **中文學習**：孩子入學前中文經驗不同，教師如何觀察理解、表達和參與？是否有分層材料、視覺提示、同伴活動或校本語言支援？
3. **家庭語言**：家長可用甚麼語言與教師溝通？通告、面談和突發聯絡如何翻譯？
4. **教職員支援**：支援由班主任、額外教師、助教、翻譯人員或外間服務提供？每週頻率和責任人是甚麼？
5. **小一銜接**：學校如何幫助孩子熟悉小學常用語言與課堂常規？是否只以「多聽中文」概括，還是有可觀察的語言支援？
6. **孩子原有語言**：教師如何了解孩子在家使用的語言、溝通方式和已有能力，不把沉默、慢熱或第二語言學習階段直接當作能力不足？

EDB在2019年為參加幼稚園教育計劃、錄取NCS兒童的幼稚園設有校本支援及額外資源安排；但本輪未找到可完整核驗的2026/27幼稚園NCS津貼額度表，因此**不引用2025/26或更早年度金額作當前數字**。EDB於2026/27推行的部分「綜合支援津貼」公告針對小學／中學，不能直接套用於幼稚園。家長應確認目標校當年度實際可用支援及其用途。[S9][S10]

## 4. 特殊教育需要與學前康復：辨識、支援、轉介、銜接分開看

### 4.1 家長可行的步驟

如家長或教師持續觀察到孩子在溝通、動作、社交情緒、感官、學習或日常適應方面需要額外協助：

1. 先記錄具體情境、出現頻率、已有效的方法，以及家中與學校是否相同；避免用網上量表自行診斷。
2. 與班主任／校長安排會面，詢問校內觀察、課堂調適、家校跟進及轉介流程；提出需要不必等同已取得正式診斷。
3. 按官方流程向母嬰健康院／相關醫療及社會服務單位查詢評估或支援；EDB的「兒童身心全面發展服務」（CCDS）由教育、衞生及社會服務協作，目標包括及早識別及提供適時支援。[S11]
4. 如考慮到校學前康復、兼收或其他服務，核對孩子的評估／服務資格、學校是否參與、輪候或轉介路徑，以及服務提供者和家長的配合方式。不要將「學校有服務」理解為每名孩子都自動取得治療名額。[S6]
5. 要升小一的孩子，及早與幼稚園、目標小學和相關專業人員安排支援交接；涉及特殊教育需要資料的轉交，須按教育局程序處理並取得家長同意，家長亦可了解資料用途、查閱和更新權利。[S12]

本文不是醫療建議；家長如對發展或健康有疑慮，應向合資格專業人士查詢，不宜依影片內容延誤評估或支援。

### 4.2 2026學前康復服務校本模式：可用數據與不可推論之處

社署資料顯示：

- 第一階段12所KG／KG-cum-CCC於**2026年4月1日**加入試行；
- 第二階段另有100所於**2026年9月1日**加入，合共112所；
- 2026年8月資料列出2027年2月至8月為服務過渡期，並預計**2027年9月**在全港設有兼收計劃或到校學前康復服務的KG／KG-cum-CCC推行新模式。[S6]

新模式整合兼收計劃（IP）與到校學前康復服務（OPRS）的協作；社署資料稱，在校本模式下，合資格孩子可透過校內服務協作支援，免除中央輪候程序。適用前提是孩子符合相關資格，且學校在模式／服務名單內；非參與學校家庭要按既有服務路徑處理。每次申請前應重新查閱社署參與學校名單和轉介安排。[S6]

**資料狀態提醒：**截至研究日，社署概覽頁仍以將來式寫第二階段於2026年9月1日開始；參與學校名單則已註明第二階段學校由該日起毋須經中央轉介系統申請。逐校核實時應以當期名單及社署確認為準，不只引用未更新的概覽文案。[S6]

2026/27另有面向正在接受OPRS服務兒童的小一首學期銜接／支援安排。政府亦公布2026/27年度增加約450個日間、住宿及學前康復服務名額；這是跨服務合計，不是450個幼稚園名額，更不是全港SEN幼兒人數。[S17]

**統計解讀提醒：**學前康復服務名額、中央輪候人數、服務使用人數與全港有支援需要的幼兒人數不是同一指標。2026年服務模式正在轉換，不能把不同服務類別的輪候數相加，當成兒童需要率或家長獲服務概率；本輪不發布全港「SEN幼兒比例」或服務成功率推算。

## 5. K3至P1幼小銜接：用「適應能力」而非「提早上小學」來規劃

EDB的《幼稚園教育課程指引（2017）》設有「從家到校適應」及「幼稚園與小學銜接」章節；教育局另有《幼小佳》家長小冊子和四類延展活動資源，包括自理、體能、情意及認知。2024《小學教育課程指引》第9章指出，跨階段銜接會帶來轉變和挑戰，孩子所需適應期因人而異，學校和家長應尊重差異並提供適切支援。[S1][S7][S8]

### 5.1 家庭可用的K3準備清單

以下是**家庭規劃清單，不是EDB統一考核表或入學門檻**：

| 面向 | 可以逐步練習 | 不要變成 |
|---|---|---|
| 自理與安全 | 收拾個人物品、如廁／洗手、表達身體不適、知道向可信任成人求助 | 要求孩子完全不需成人協助 |
| 日常節奏 | 配合合理睡眠、早起、用餐和通勤安排；熟悉上學與放學流程 | 入學前以高壓作息操練取代漸進適應 |
| 情緒與社交 | 說出感受、輪流、等待、遇到困難求助、與同伴協商 | 把安靜、慢熱或需要時間理解指令直接說成「不合群」 |
| 學習習慣 | 聽故事、提問、整理材料、完成短而有意義的活動 | 長時間坐定、抄寫和反覆做題當成小一準備 |
| 環境轉換 | 參加小學迎新／參觀（若學校安排）、先看校園照片、談一日流程 | 把單次參觀或暑期班當成適應保證 |
| 家校協作 | 向小學說明有效溝通方式、語言及支援需要 | 假設幼稚園會自動把所有個人資料交給小學 |

### 5.2 有特殊教育需要孩子的銜接

教育局要求學校在家長同意下按程序傳遞相關資料，讓接收學校可及早了解孩子的支援需要；可以交接的資料包括評估／醫療報告、幼稚園已有支援、學習紀錄和教學建議等。家長應主動問清楚：由誰聯絡小學、傳甚麼資料、何時傳、同意如何處理，以及新校首學期由誰跟進。接收小學須由學生支援組審閱資料並與家長討論；按EDB現行安排，學校應於每學年10月下旬或之前向家長提供「幼小銜接支援概要」，說明校本支援措施。[S12]這是**同意後的支援交接**，不是所有幼兒個人資料的自動轉檔。[S12]

普通兒童的幼小銜接與SEN資料轉移是兩件事：前者是普遍的課程與生活適應，後者只涉及需要支援的孩子和相關資料處理。勿把特殊教育行政流程誤說成每名K3兒童都必須交醫療紀錄。[S7][S12]

## 6. 逐校資料核查：把宣傳語改成可比較的證據

### 6.1 師生比例：制度門檻不等於孩子每天的實際照顧比例

EDB通告規定，參加幼稚園教育計劃的KG由2022/23學年起須按**1:11整體師生比例（校長不計入）**聘用足夠持有幼兒教育證書或以上學歷的教師。[S18] 這是學校整體的人手規定，不能直接解讀成每班每天都由一位教師照顧11名兒童，也不表示班主任在所有時段都能單獨提供個別支援。比較學校時應另外問：目前實際班額、同時在場的合資格教師和助教人數、半日／全日班的人手輪替、支援服務人員是否計入，以及有需要時由誰協調。

| 維度 | 優先查證資料 | 可追問問題 |
|---|---|---|
| 校本課程 | EDB幼稚園概覽、學校課程簡介、年度學校報告／Quality Review Report（如適用） | 課程怎樣平衡六個學習範疇？教師如何觀察與跟進？ |
| 遊戲與活動 | 一日流程、課室環境、活動例子、家長觀課安排（如有） | 孩子有多少自主探索？教師如何把遊戲連到學習目標？ |
| 語言 | 教學語言時段、中文／英文／普通話安排、NCS家庭溝通與支援 | 「全英／英普」是誰教、每日多久、孩子不理解時如何支援？ |
| 發展差異 | SEN識別和轉介流程、校本調適、服務名單及家長合作 | 未取得診斷前，學校可以先提供哪些課堂調適？ |
| 小一銜接 | K3活動、家長講座、小學合作、升小支援安排 | 活動目標是否包括自理、情緒、社交及學習習慣，而非只操寫字？ |
| 質素保證 | EDB Quality Review Reports、學校自評／學校報告 | 報告年份和學校後續改進是甚麼？哪些項目只有校方自述？ |

品質資料的適用範圍要說清楚：參加KG Scheme的學校須持續進行學校自我評估並接受EDB Quality Review；不參加KG Scheme的學校也獲鼓勵參照指標自評，但家長不能假設每校都有同一套公開QR報告。QR是持續改善與問責證據之一，不是排名，也不保證個別班級或某一位孩子的結果。[S13][S14]

## 7. 常見誤區與可安全口播

### 不應這樣說

- 「香港幼稚園就是玩，沒有課程。」——忽略了官方課程框架、教師設計和學習觀察。
- 「孩子越早會寫字、背詞、做小學題，升小一越有優勢。」——把機械操練當成幼兒教育目標，與EDB幼兒課程指引的全人、適齡原則不符。
- 「遊戲為本就是完全放任。」——忽略成人規劃、引導、觀察和安全責任。
- 「NCS就是不會中文／英文較好。」——以支援分類推斷個人能力，無官方依據。
- 「幼稚園有到校服務，所有SEN孩子都會立刻獲得治療。」——忽略服務資格、學校參與名單及服務轉型安排。
- 「幼稚園會自動把孩子完整檔案交給小學。」——特殊教育需要資料轉交須按程序及家長同意處理。

### 約30秒口播稿

> 「香港幼稚園不是把小學課本提前教完。教育局課程有五大發展目標、六個學習範疇，透過生活主題、遊戲和探索培養孩子；遊戲不是放任，家長要看教師怎樣設計和跟進。教育局也提醒，幼兒班不應要求孩子寫字。升小一更不等於越早操寫越好，自理、表達、情緒適應和家校溝通都要規劃。若孩子需要額外支援，要及早問清楚學校服務資格、轉介和小一交接。」

## 8. 研究缺口與下一步

### 本輪已核實

- 以EDB現行幼稚園教育課程指引及「應做和不應做事項」建立課程判讀框架；確認幼兒班書寫、課程過重及知識灌輸等官方提醒。
- 以EDB 2027/28 NCS K1支援頁核實多語申請資料及2026年7月11日家長講座資訊。
- 以SWD 2026年8月校本支援模式資料核實試行學校數、開始日期及2027年9月預定擴展範圍。
- 以EDB 2024小學課程指引和特殊需要資料轉交指引，區分普遍幼小適應與同意後的SEN支援交接。

### 尚待逐校／逐服務核實

- 沒有建立全港KG逐校課程語言、教師部署、校本NCS津貼、SEN服務參與和班別資料表；本報的核查表不能代替學校當年度書面答覆。
- 沒有使用學校宣傳頁推算「英語成效」「升小成績」或幼稚園到小學的因果結果；公開資料不足以做此類排名。
- 2026/27幼稚園NCS校本支援的當年度撥款額和各校實際部署尚未逐校核對；不沿用往年金額。
- 2027年9月校本康復模式擴展是社署公布的未來安排，執行前應重新確認最新參與校名單、轉換期和兒童資格。
