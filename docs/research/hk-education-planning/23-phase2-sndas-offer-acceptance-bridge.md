# 香港中六至大學升學出口研究 23：SNDAS 直接錄取、接受與 JUPAS 的關係

*研究基準日：2026-10-10（香港）｜用途：香港教育規劃影片系列｜證據類型：政府統計／政策原文、研究者複算及未核實缺口*

## 摘要

本輪補上了一條「有接受offer人數、但不可併入JUPAS接受率」的直接錄取路徑。教育局公布的2026屆第五屆SNDAS有847份有效提名，來自433所中學；八所教資會資助大學在DSE放榜前發出325份直接錄取firm offer，其中319人接受。以同屆數字複算，提名至offer為38.37%，offer至接受為98.15%。這兩個比例只描述經中學提名後的SNDAS配對及選拔流程，**不是學生的個人錄取機率、JUPAS成功率，也不是完成註冊／實際入讀率**。官方2026年7月9日公告用語為接受者「將於2026年9月入讀」；目前這個數據點不能單獨證明開學後的正式註冊或到校情況。[S1]

同時，2027/28（第六屆）正在進行提名：教育局列出的提名期為2026年10月7日至12月2日；本地中學每校最多提名兩人，每位學生只可申請一個指定課程，並須同步申請JUPAS。指定課程清單於2026年10月8日更新，共316個公帑資助本科課程；316是**課程數，不是學額、offer數或錄取人數**。[S2][S3][S4][S5]

## 1. 2026第五屆：可建立的SNDAS內部漏斗

| 階段 | 官方人數 | 同屆比例（研究者複算） | 正確解讀 |
|---|---:|---:|---|
| 有效提名 | 847，來自433所中學 | — | 已先經中學提名的候選人，不是所有DSE考生 |
| DSE放榜前發出firm offer | 325 | 325 ÷ 847 = **38.37%** | SNDAS計劃內「有效提名→offer」的聚合比例；不是個人錄取機率 |
| 接受firm offer | 319 | 319 ÷ 325 = **98.15%** | SNDAS offer接受比例，不是JUPAS繳費接受率 |

來源公告表示，八所UGC資助大學先對獲提名學生進行面試及評核，於2026年DSE放榜前發出325份直接錄取offer；319人接受並預定於2026年9月入讀其所選UGC資助本科課程。尚有6份offer未被列入「已接受」數；公告沒有說明其原因，不應自行標記為拒絕、逾期或放棄。該公告另指學科分類明細見附件；本輪資料集只登錄總量，**未逐學科抽取附件**。[S1]

### 這兩個比例不能怎樣用

- `325/847` 的分母已經過中學提名篩選；而SNDAS是課程與學生配對、大學會面試／按個別課程要求甄選，不能講成「DSE考生有38.37%機會入大學」。
- `319/325` 是在DSE放榜前接受SNDAS firm offer的比例，不是JUPAS接受費繳付率，也沒有把其後完成院校註冊列作分子。
- 第五屆接受數319與2026 JUPAS Main Round的一般offer數、SSSDP offer數，不可直接相加成「全港大學錄取總數」：路徑、事件時間、課程分類與去重口徑不同。2027/28現行SNDAS規則明確指出，接受直接錄取後具有約束力，JUPAS申請會從系統自動移除；但不可未核對第五屆逐年規則與統計母體，便把該規則倒推成2026 JUPAS公開表的去重算法。[S5]

## 2. 2027/28第六屆：截至2026-10-10的家庭與學校行動點

| 項目 | 官方安排 | 規劃含義 |
|---|---|---|
| 對象 | 修讀本地中學課程並應考2027 HKDSE的本地學生；須同時經JUPAS申請 | 先核對學生是否符合SNDAS與JUPAS兩套資格，不能只看在港就讀 |
| 提名窗口 | 2026-10-07至2026-12-02 | 截止日前由中學按個別課程要求提交，家長需及早向學校問校內甄選日期 |
| 校內提名 | 每所本地中學上限兩名 | 是校方提名配額，不是院校學額；校內競爭先於大學選拔 |
| 課程選擇 | 每位學生一個指定UGC資助本科課程；必須列入JUPAS 20個課程選擇，部分課程要求Band A | 必須逐課程檢查學術門檻、作品／活動材料、面試／筆試及選擇次序 |
| 大學評核 | 院校會為獲提名學生安排面試，亦可能加設筆試或實作評核；實際日期依課程要求 | 不應只憑中學排名或DSE預測級別推估錄取 |
| Offer與接受 | 預計2027年6月、DSE放榜前發直接錄取通知；接受具約束力，JUPAS帳戶自動移除 | 這是「提前確定」與「保留DSE放榜後選擇」的取捨；接受前須看清不再獲其他課程考慮的後果 |
| 課程供給 | 316個指定公帑資助本科課程（名單截至2026-10-08） | 316不是學額；各課程錄取規模未由此數字交代 |

上述規則按2027/28當屆EDB頁面記錄。EDB亦說明，列入HKEAA HKDSE參與學校名單的內地港人子弟學校學生，如符合計劃資格，亦可被提名；故不應粗略說成「只限香港境內校舍就讀者」，但仍須核對JUPAS及課程個別要求。[S2][S3][S5]

## 3. 身份與居港資格：與SNDAS並行申請的交叉風險

SNDAS要求同步申請JUPAS；因此，持受養人簽證／進入許可的家庭不能只確認「本地中學、應考DSE」便假設JUPAS資格已滿足。2027 JUPAS的持受養人簽證／進入許可的CATI-5申請人須同時符合身份文件和居港要求。2027 JUPAS設一年過渡期（2026年6月1日至2027年5月31日）；以在港認可學校全日制就讀作證明者，須不遲於2026年9月15日入學。JUPAS可按個案要求學校就讀證明、入境處旅遊紀錄或兩者組合；如以旅遊紀錄計算，每個適用年度不在港日數不得超過90日。2028年度起適用兩年居港期，故不能把2027過渡規則沿用到下一屆；家庭應逐人用官方文件核對。[S6]

## 4. 對上一輪「offer→接受→註冊」缺口的更新

- **已補上的部分：**找到2026第五屆SNDAS有319名接受直接錄取offer的官方aggregate數，並可用325份firm offer作同屆接受比例分母。
- **尚未補上的部分：**本輪查到的2026官方公告在2026年7月發布，描述319人將於9月入讀；未找到開學後這319人的正式註冊／實際入讀aggregate確認。故資料表保留「接受offer」狀態，不升格為「已註冊」或「已入讀」。
- **JUPAS缺口仍然存在：**上一輪查核的JUPAS公開頁面沒有2026全體已繳費接受或完成院校註冊總數。SNDAS 319不能填補該欄，也不能代表JUPAS主輪接受率。見研究報告22。
- **分學科缺口：**官方說明有SNDAS offer接受學科分布附件；本輪尚未抽出表格，因此不發布「哪些學科最多」的說法。
