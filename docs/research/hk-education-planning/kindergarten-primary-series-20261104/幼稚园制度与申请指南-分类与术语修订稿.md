# 内地家庭看懂香港幼稚园：制度、报名、面试与孩子未来的路

学校分类与术语补充核对：2026年11月5日；原有年度资料核对日期：2026年11月4日。本文以2027/28学年K1招生为年度实例，另行注明当前学年的资助资料。学校例子用于说明机制差异，不构成排名或推荐；未来申请应重查当届文件。

初到香港的家长，可能同时听到“学券”“龙幼”“细B”“交留位费”，却不知道它们属于不同层面的事情。有些涉及政府资助，有些是学校规定，有些只是家长圈简称。把它们混在一起，很容易以为报了一所幼稚园就能锁定小学，或以为拿到录取便已完成入学。

理解这套体系，可以从三个问题开始：孩子能否在港就读、家庭希望接下来怎样生活、这所学校实际怎样教育孩子。然后再处理报名、面见和注册。

## 一、先认识学制：PN和K1不是同一班

香港幼稚园通常包括幼儿班K1、低班K2和高班K3，为三至六岁儿童提供教育。幼稚园全属私营，由志愿团体或私人开办，分非牟利和私立独立两类。因此，“政府有资助”不表示学校是官立。[教育局：幼稚园教育概览](https://www.edb.gov.hk/sc/edu-system/preprimary-kindergarten/overview/index.html)

| 常见名称 | 应怎样理解 | 家长先核对什么 |
|---|---|---|
| PN、Pre-Nursery、N班、N1 | 不同机构对幼稚园前阶段班级的称呼，不能只凭名称判断服务 | 出生日期范围、获准入读年龄、照顾时数、监管与收费资料 |
| K1／幼儿班 | 通常是三年幼稚园教育的起点 | 学校当届年龄要求及招生安排 |
| K2／低班 | K1之后的一级 | 转入其他学校须查插班程序及空缺 |
| K3／高班 | 通常进入幼小衔接阶段 | 小学报名可能在本级开学前后已经开始 |
| AM／PM | 上午班／下午班 | 实际上下课时间、校车和接送安排 |
| WD／全日、长全日 | 不同服务时长 | 午睡、膳食、假期、延长照顾与额外收费 |

社署的幼儿中心服务对象为三岁以下幼儿，包含独立幼儿中心及附设于幼稚园的幼儿中心。不要把PN的照顾服务、K1的教育计划和所有资助视为一套规则。[社署：幼儿中心服务](https://www.swd.gov.hk/tc/pubsvc/family/cat_childcareservice/daychildcares/cccs/)

报名时还要注意英文名称。教育局K1文件中的“Nursery”指幼儿班；其他学校口中的Nursery可能采用另一套年级名称。最可靠的办法是同时写下出生日期、入学学年、班级全名和开学日期，再请学校确认。

### 英基是什么？与本地幼稚园的年级有什么不同？

“英基”是**英基学校协会**（English Schools Foundation，简称ESF）的中文简称，是在香港营办幼稚园、小学及中学的办学机构，不是国际学校的统称。英基幼稚园一般分K1和K2，之后进入小学Year 1；本地幼稚园通常为K1、K2、K3，之后升读小学P1。年级名称及年龄划分不同，家长应以孩子生日查英基当届年级表和申请时间，不要等本地K3才首次查看。[英基：幼稚园招生](https://join-us.esf.edu.hk/admissions-kindergarten/)、[英基：升学衔接](https://join-us.esf.edu.hk/transitions-and-transfers/)

英基公布的幼升小安排有入读K2的时点及教育需要等条件，体系内学位也不保证第一志愿学校；具体条件见本文“龙幼”部分及当届公告。

### “大B／细B”会决定入学机会吗？

“B”是宝宝的俗称。“大B／细B”通常指同一入学届别中相对年长／年幼的孩子，不是身高或能力等级；“超大B”常指迟一年入学或重读后，比新一届多数同学年长的孩子。这些是民间用语，月份界线没有统一标准，比较时先说明出生年月和入学届别。

例如以2027年9月1日入读K1计算：2024年1月出生约三岁八个月，通常会被称为大B；2024年11月出生约两岁十个月，常被称为细B；2023年11月出生、迟一年在2027年入读K1的孩子约三岁十个月，可能被称为超大B。这只是按出生月作相对比较，不能预测面试结果。

教育局将九月入读幼稚园的最低年龄放宽为两岁八个月；2027/28学年注册证申请指引列明，K1儿童须在2024年12月31日或之前出生。达到这个界线不表示任何学校都有义务录取，仍须看学校年龄范围和收生机制。[教育局：2027/28注册证申请指引，第2、4页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/RC%20Guidance%20Notes%202027_28_Chi_Clean.pdf)

家长若考虑晚一年入学或重读，应把儿童状态、年级衔接和费用一起考虑。政府通函说明，注册证通常对应三年幼稚园教育；自行延长就读超过三年，一般需要支付未扣除计划资助的全额学费，特殊需要的延长申请另有证明要求。[教育局：通函80/2026，第4页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/EDBCM80_2026_TC.pdf)

## 二、看学校，要分开看四个维度

第一是办学性质，第二是有无参加幼稚园教育计划，第三是课程与教学语言，第四是服务时长。同一所学校可以同时拥有这四种属性；“私营”“本地”“双语”“全日”不是互相排斥的四类学校。

政府自2017/18学年起推行幼稚园教育计划，向合资格本地非牟利幼稚园提供资助，并对全日及长全日服务额外增拨资源。收生原则上仍由学校处理。[教育局：幼稚园教育计划](https://www.edb.gov.hk/tc/edu-system/preprimary-kindergarten/free-quality-kg-edu/index.html)

“学券”是旧制度留下来的常见叫法。教育局概览明确说明，幼稚园教育计划自2017/18学年取代学券计划。今天听到“学券幼稚园”，应追问对方是否指参加现行教育计划的学校。[教育局：幼稚园教育概览](https://www.edb.gov.hk/sc/edu-system/preprimary-kindergarten/overview/index.html)

“国际”“英文”“两文三语”也不能直接当作质量评级。两文是中文、英文；三语是粤语、英语和普通话。家长需要了解每种语言在真实课堂出现的场景，而不是只计算宣传册中列了几种语言。[教育局：幼稚园课程问答](https://www.edb.gov.hk/tc/curriculum-development/major-level-of-edu/preprimary/questions-and-answers.html)

建议把下面的问题带到开放日：主要活动用什么语言？孩子听不明白时老师怎样协助？同伴交往主要用什么语言？中文阅读如何展开？学校如何向家长反馈，而不只展示成果表演？

### 先把“学校性质”和“课程标签”分开

香港幼稚园都由非政府机构营办，按办学性质分为**非牟利幼稚园**和**私立独立幼稚园**。这说的是办学模式；有没有政府资助、用什么课程、提供多长照顾，是另外的问题。

| 怎样分 | 名称与定义 | 对家长有什么影响 |
|---|---|---|
| 办学性质 | 非牟利：获教育局认可为非牟利，例如符合《税务条例》第88条获豁免缴税，或属获豁免机构的认可附属机构；不表示不收学费 | 符合条件的本地非牟利园可以参加幼稚园教育计划；也有非牟利园不参加，须逐校核对 |
| 办学性质 | 私立独立：教育局分类中不属认可非牟利类别的另一种营办模式；不能只凭“私营”两个字判断 | 不属于现行计划资助对象；看该校核准学费与额外支出 |
| 是否参加计划 | “计划园”“券园”：家长口中的券园通常指参加现行幼稚园教育计划的园所；“学券”是旧称 | 符合条件的孩子在计划园就读时，学校按计划获得资助；仍须核实际应缴费用和资助资格 |
| 是否参加计划 | 非计划园：该学年没有参加幼稚园教育计划，可以是非牟利或私立独立 | 不享该计划学费资助；不等于不受监管，须查看核准费用 |
| 服务机构 | 幼稚园：主要提供K1至K3教育；幼稚园暨幼儿中心：同一机构还提供幼儿中心服务 | 学校名称含“暨幼儿中心”不代表PN必有空位；核实年龄、班别、费用及监管资料 |
| 课程与语言 | 本地／非本地课程、粤语／英语／普通话、双语／国际等，是课程或语言描述 | 与办学性质、是否参加计划交叉；“国际”“英幼”不是统一课程认证，也不保证英语课时或小学学位 |
| 上课时间 | 半日AM／PM、全日及长全日描述服务时长 | 分别查接送、午膳、假期和额外费用，不能只看“全日”二字 |

**一所学校可以同时是非牟利、计划园、双语及全日制；另一所也可以是非牟利但不参加计划。** 查学校时，把“性质、当学年计划状态、课程语言、服务时长”分四栏记录，才能比较实际费用和孩子每天的学习环境。教育局把所有幼稚园列为私营，不代表每所都是私立独立或都以营利为目的。[教育局：幼稚园教育概览](https://www.edb.gov.hk/sc/edu-system/preprimary-kindergarten/overview/index.html)、[教育局：幼稚园教育计划问答，非牟利定义](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/free-quality-kg-edu/FAQ_KG%20Scheme_20241113_TC.pdf)、[教育局：非计划园收费通函](https://applications.edb.gov.hk/circular/upload/EDBCM/EDBCM25002C.pdf)、[社署：幼儿中心服务](https://www.swd.gov.hk/tc/pubsvc/family/cat_childcareservice/daychildcares/cccs/)

## 三、远期规划：先想希望保留什么选择

家长当然可以有期待：希望孩子在香港扎根、将来往海外发展、保留回内地生活的可能，或者暂时还没决定。幼稚园阶段值得明确的是家庭未来几年的生活条件，以及孩子需要建立什么基础。

以下是规划建议，不是政府对家庭路线的分类，也不代表某一种课程必然带来更好的结果。

| 家庭目前的方向 | 幼稚园阶段重点观察 | 需要同步准备 | 避免怎样理解 |
|---|---|---|---|
| 准备长期在港，主要考虑本地小学 | 粤语沟通、中文接触、生活自理、真实的幼小衔接 | 了解目标小学究竟通过派位还是校本招生 | 幼稚园有名气，就能为官津小学加分 |
| 倾向国际课程或未来迁居海外 | 孩子能否理解课堂语言，学校怎样发展表达、阅读与探究 | 查询下一阶段学校的年级、语言要求和长期费用 | 校名有“国际”便保证接入某所小学 |
| 未来可能回内地 | 中文阅读、表达与适应不同课堂的能力 | 向目的地教育部门及学校确认学籍、年级与转入要求 | 在港读过幼稚园便能无条件转入任意学校 |
| 暂未决定 | 孩子愿意交流、能建立同伴关系，中文与英文均有持续接触 | 保留学习记录，每学年复盘下一阶段选项 | 为“保留所有选择”而把孩子每天排满课程 |
| 孩子需要额外发展支援 | 教师观察、沟通方式、专业支援和学校承接能力 | 与专业人员及学校讨论服务和衔接 | 先抢到名校学位，再处理适应与支援 |

例如，两所学校都强调英文，一所能清楚解释怎样帮助普通话家庭的孩子理解日常指令，另一所只展示英文表演视频。对刚到港的家庭，前一种信息更能帮助判断孩子每天会经历什么。这是比较方法，不是对任何具体学校的评价。

“保留选择”还包括家庭承受能力。可以做一张三年预算，列学费、校服用品、交通、膳食、照顾及可选择活动，再检查一名家长工作变化或家庭迁居时是否仍能维持。不要只比较第一年的学费。

## 四、“龙幼”究竟能保什么？

“龙幼”是家长圈对有小学衔接优势的幼稚园的俗称，不能只凭这个标签判断。要把“同一办学团体”“优先面试”“内部申请”“有条件保证学位”和“保证进入指定学校”逐项分开。

教育局说明，幼稚园不能保证毕业生直升官立或资助小学。至于私立、直资及英基学校的小一，并不纳入小一入学统筹办法，须向相关学校申请。[教育局：幼稚园课程问答，第3题](https://www.edb.gov.hk/tc/curriculum-development/major-level-of-edu/preprimary/questions-and-answers.html)

英基现行网页提供了一个需要细读条件的实例：能够受益于主流英语课程的英基幼稚园学生，有体系内Year 1衔接安排；网页列出K2在12月1日前入读的条件，较晚加入而遇上Year 1录取已发出的情况，不保证仍有小学学位。需要特殊教育环境的儿童也须另外确认合适安排。“体系内有学位”不表示保证家长第一志愿的小学，家长应查自己孩子所属届别的规则。[英基：幼稚园申请及升小学安排](https://join-us.esf.edu.hk/kindergarten-admissions-process/)

看升学成绩表时，也应追问：统计哪个学年？分母是全体毕业生、申请者还是收到录取者？一个孩子收到多个录取是否重复计算？学校未说明，就不能把“若干录取”直接换成自己的录取概率。

## 五、入学资格、学校录取、资助资格分开查

内地家庭首先要核对孩子本人的有效证件、获准逗留条件和期限。父母某项申请获批，不等于孩子已经完成相关入境及居留手续；学校发录取信也不能代替就学许可。非本地儿童在港就学须符合入境部门批准条件。[教育局：通告16/2025](https://applications.edb.gov.hk/circular/upload/EDBC/EDBC25016C.pdf)

在参加教育计划的幼稚园，常见的两种文件是“幼稚园入学注册证”和“幼稚园入学许可书”。前者与符合计划资助资格有关；后者用于可在港接受教育但不符合相关资助资格的儿童，家长须支付未扣除计划资助的学费。不要把“入学许可书”理解成任何访客均可取得的上学通行证。[教育局：2027/28收生安排指引，第3页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/202728_Admission%20Guidelines_TC.pdf)

**注册证不是学校录取通知书，也不会替孩子自动报名。** 家长须分别向学校申请学位、向教育局申请注册文件，再在获录取后完成学校注册。

有关身份的问题应提交完整证件向教育局或入境处确认，尤其留意电子签证、入境记录及有效期限。单看“受养人”“港宝”等口头称呼，无法替代审核。

实际办理时，即使预计只符合“入学许可书”，也使用同一份注册证申请表，由教育局审核发出相应文件。指引列明，只持旅游签证、双程通行证或学生签证，不符合注册证资格；这并不表示可以自动取得入学许可书，能否在港就学仍须另核许可。文件齐全后审核通常需六至八周，补件会延长。学年中途才入读，建议注册／入学前六至八周申请，并非过了11月30日就全年不能办理。[教育局：申请指引，第1—3页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/RC%20Guidance%20Notes%202027_28_Chi_Clean.pdf)

## 六、怎样安排2027/28学年的申请

下表适用于教育局当届K1收生安排涉及的学校。非计划幼稚园是否参加相关安排、参加形式及各自日程，仍须逐校确认。

| 时间或节点 | 家长行动 |
|---|---|
| 学校公布报名资料时 | 查看出生日期范围、报名期限、材料、面见及收费；每校分别记录 |
| 2026年9月至11月 | 向教育局申请注册文件，与学校报名并行进行 |
| 2026年11月起 | 按学校通知参与面见；相关指引要求新生参与的下年度K1招生程序不早于11月 |
| 最迟2026年11月30日 | 及时递交注册证申请，以预留审核时间；不是全港学校统一报名截止日 |
| 2026年12月11日前 | 相关学校通知K1申请结果；记录正取、候补及回复要求 |
| 2027年1月7日至9日 | 在学校指定时段到选定的一校办理统一注册 |
| 2027年1月底起 | 如仍需学位，查询教育局K1—K3空缺资料并联系学校 |

日期依据：[教育局注册证申请指引，第1—2页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/RC%20Guidance%20Notes%202027_28_Chi_Clean.pdf)、[当届收生流程及通函](https://www.edb.gov.hk/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/2728_admission_arrangements.html)。这些是2027/28实例，不能原封不动用于下一届。

### 学校申请时间为什么必须单独查？

截至本次核对，救恩学校幼稚园页面说明2027/28 K1申请已截止；青乐幼稚园／幼儿园（西湾河）页面说明全年接受网上申请，并会面见所有申请儿童。两种做法不能互相套用。[救恩入学申请](https://primary.kauyan.edu.hk/kindergarten/admissions/)、[青乐入学申请](https://clswh.hkfyg.org.hk/2026-2027%E5%AD%B8%E5%B9%B4%E6%94%B6%E7%94%9F%E5%AE%89%E6%8E%92/)

维多利亚教育机构公布的2027/28 K1报名期为2026年9月7日至10月26日，PN则是9月14日至12月14日；K1与PN的面见和结果日期也不同。[该机构重要日子](https://www.victoria.edu.hk/zh-hk/key-dates/)

铜锣湾维多利亚幼稚园暨国际幼儿园的独立官网则列自己的PN出生日期范围、报名期限及亲子面见安排。名称相近不代表共用一份申请表或一套时限。[该校2027/28 PN申请](https://www.cbvictoria.edu.hk/en/pn_application/)

以上例子说明，家长要保存所申请校舍的正式网址、学年及班级，不要只保存一张“全港截止日期”截图。

临近注册或学年中途才来港的家庭，可以并行处理三件事：核实儿童有效就学及居留文件，查询学校空缺和面见安排，预留注册文件申请时间。已在其他幼稚园注册者还须处理原校取消注册。先问学校是否接受该级插班、何时能入学，不要把“有空缺”理解成无条件立即就读。

有照顾需要的家庭应同时留意全日班准则。教育局要求相关全日／长全日服务在收生时优先考虑确有服务需要的家庭，例如双职或有特殊照顾需要者；学校须公开相关条件。全日班不只是比半日班多上一段课。[教育局：收生安排指引，第2页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/202728_Admission%20Guidelines_TC.pdf)

## 七、材料清单：分清交给谁

以下是建立文件夹的方法，并非每所学校一律要求全部材料。应以政府当届指引及学校申请表为准。

接收方可先分三组：教育局注册文件申请主要核对申请人、儿童身份及监护等证明；学校报名按申请表收取照片、资料及适用费用；录取后入学再按要求提交健康、接送、紧急联系等资料。同一文件可能在不同阶段核验，不应把一个部门收妥材料当成所有手续已办妥。

| 材料 | 用途与注意事项 |
|---|---|
| 孩子身份证明及出生资料 | 核对姓名、出生日期与亲子关系；非香港出生儿童须按要求提供有效旅行及居留资料 |
| 家长／监护人身份证明 | 政府申请与学校核验；由其他照顾人申请时，查授权及关系证明要求 |
| 签证、入境和逗留记录 | 证明当前就读资格及有效期；续期后查询是否需更新注册文件 |
| 学校申请表、照片及付款记录 | 按校本要求准备；保存提交成功页面、编号和确认邮件 |
| 通讯资料 | 确保能接收邮件、电话及信件；搬家或联系方式改变应及时更新 |
| 面见通知、录取信及回复文件 | 分清回复截止日、注册日与开学日 |
| 健康、疫苗及发展资料 | 入学前按学校要求提供；如需支援，可提前讨论怎样交接已有评估与服务记录 |

教育局注册证指引列有申请人、儿童及特殊监护情况的证明要求。家庭应指定一名申请负责人，避免父母双方重复提交；填写姓名须与证件一致。[教育局注册证申请指引，第4—6页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/RC%20Guidance%20Notes%202027_28_Chi_Clean.pdf)

建议另建申请进度表，记录“已提交、已确认收妥、获邀面见、候补、获录取、已注册、已取消”。提交申请、收到系统邮件和获录取，是三个不同状态。

## 八、面试准备：先问学校怎样见孩子

“面试”在学校文件中也常写作“面见”或“面谈”。可能涉及儿童活动、家长交流或分阶段安排，但不能把某校的题目当成全港标准。

例如，维多利亚教育机构当届FAQ列明，适龄申请者在报名期内完成网上报名可安排第一次面见；无法到场的海外申请另有申报及影片安排。英基则说明Play Visit用于观察儿童、与家长交流，并判断学习环境是否适合孩子；并非每位申请者都会获邀。[维多利亚FAQ](https://www.victoria.edu.hk/zh-hk/faq/)、[英基申请程序](https://join-us.esf.edu.hk/kindergarten-admissions-process/)

教育局收生指引要求尊重儿童发展，不应安排超出该年龄层发展程度的活动或知识要求。[教育局2027/28收生指引，第3页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/202728_Admission%20Guidelines_TC.pdf)

家庭可以提前做四件实际的事：

1. 核实地点、陪同人数、所用语言、材料及改期办法。
2. 维持日常作息，给孩子与其他儿童游戏、向成人表达需要的机会。
3. 家长认真了解学校，能够说明选择原因及孩子平常的兴趣、需要。
4. 如孩子有语言或发展支援需要，提前询问合理安排，提供真实资料。

不用把“面试准备”变成背诵表演。面对学校问题，家长可具体说明：“他现在主要说普通话，听不懂指令时会看同伴，希望了解老师怎样帮助新生。”这比笼统声称孩子语言能力优秀更便于学校判断支持方式。

## 九、录取、候补和注册：学位怎样才算落实

正取通常指获录取；备取或waiting list指仍在候补；offer通常指录取通知，但也可能附条件。家长应阅读信件，确认下一步，而不是只凭一个英文词判断。

当届安排下，相关幼稚园以注册文件办理“一人不占多位”。电子文件带有加密二维码，注册和取消注册涉及学校扫描；新发电子文件与仍在有效期内的旧版纸本文件，处理方式有区别。转校前应安排两校之间的衔接，确认新校条件及可注册时间，再按程序取消原校注册。[教育局2027/28常见问题，第1—2页](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/FAQ%202027_28_TC.pdf)

取消注册后，原校不再为儿童保留学位，已缴注册费一般不退；不要先取消唯一可用的学位，再把尚未落实的候补当作替代。[教育局：当届注册及取消注册说明](https://www.edb.gov.hk/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/2728_admission_arrangements.html)

“一人不占多位”不等于只能报名一校。但同一机构可能限制申请表数目及选择方式；每校报名规则与最终注册规则要分别看。

报名费、注册费、学费和代购费用也应分开。2027/28计划幼稚园K1报名费核准上限为40港元，半日班注册费上限970港元、全日班1,570港元；适用范围不能扩展为全港所有幼儿服务的收费规定。[教育局通函80/2026及收生指引](https://www.edb.gov.hk/attachment/tc/edu-system/preprimary-kindergarten/kindergarten-k1-admission-arrangements/202728%20K1%20Admission%20Arrangements/202728_Admission%20Guidelines_TC.pdf)

如家庭未获录取，先确认候补是否需要回复，并持续查看空缺、联系可接受的学校。不能把某校不录取理解为孩子“不适合香港教育”。新到港家庭还要先解决住址、接送与照顾安排，再决定接受哪个可行学位。

## 十、费用：把资助、学费减免和实际支出分开

学校是否参加教育计划、孩子是否符合计划资助资格、家庭是否符合额外学费减免，是三次不同的判断。

学生资助处的幼稚园及幼儿中心学费减免计划和幼稚园学生就学开支津贴，面向符合要求并有经济需要的家庭；当前2026/27资料列明年龄、课程及学校条件。不要将该页的2026/27出生日期界线直接当成2027/28规则。[学生资助处：资助计划详情](https://www.wfsfaa.gov.hk/tc/sfo/preprimary/kcfr/details.php)

看费用时，建议向学校确认：金额属于哪个学年？已扣除哪一种资助？一年分多少期？有没有膳食、校车、校服及用品？哪些活动自愿参加？退学须提前多久通知，哪笔费用能退？

2026/27《幼稚园概览》已于2026年10月15日发布，提供核准学费、师资、课程、用品参考价及支援资料，也可连接质素评核报告。计划学校展示扣减政府资助后的核准学费，仍应核对学校收费证明书。[政府：2026/27概览发布说明](https://www.info.gov.hk/gia/general/202610/15/P2026101500253.htm)、[概览查询入口](https://www.chsc.hk/kindergarten/)

## 十一、入学后：每天怎样学习，比标签更重要

香港幼稚园课程强调全面发展，通过游戏、生活经验及综合活动学习。家长可以观察孩子是否愿意提问、能否表达需要、是否逐步建立生活习惯与同伴关系，而不是只比较识字、算术和功课量。[教育局：幼稚园教育概览](https://www.edb.gov.hk/sc/edu-system/preprimary-kindergarten/overview/index.html)

教育局的“应做和不应做事项”提出，不应要求K1儿童执笔写字，不应安排机械抄写或操练式计算，也不应以默写、测验或考试评价幼儿；评估应重视持续观察。[教育局：应做和不应做事项](https://www.edb.gov.hk/tc/edu-system/preprimary-kindergarten/quality-assurance-framework/dos-donts-for-kindergartens/index.html)

对普通话家庭，建议将语言适应拆成不同问题：听不懂日常指令、不会用粤语交朋友、中文阅读经验不足和英文课堂理解困难，所需帮助并不相同。问老师具体发生在哪个情境，也把孩子在家熟悉语言中的表现告诉老师。不要仅因一段陌生语言中的沉默，就自行判断孩子能力。

有发展支援需要时，应尽早与专业人员及学校沟通。社署到校学前康复服务涉及参与学校、服务对象和不同申请途径，包含跨专业支援；第一层支援与经中央转介系统申请的安排也有区别。[社署：到校学前康复服务](https://www.swd.gov.hk/oprs/index_sc.htm)

开学前可与学校确认适应周、家长陪同、如厕及膳食安排，练习接送路线，准备紧急联系人，并将药物、过敏及既有支援资料按要求交接。半日班上课以外由谁照顾、学校假期怎样安排，最好在注册前就解决。

## 十二、从幼稚园走向小学，什么时候复盘？

以下是家庭行动建议，不是统一招生时间表：

先确认目标体系的年级结构：本地常见K1—K3后升P1，英基则有K2后升Year 1的衔接，不能统一等到K3才行动。建议在K1期间就查询目标体系。[英基官方年级及衔接安排](https://join-us.esf.edu.hk/kindergarten-admissions-process/)

- **报K1前：** 明确居留、接送、预算及照顾条件，初步考虑本地或国际小学方向。
- **K1期间：** 观察真实适应、沟通与学习兴趣；复盘原来对语言环境的判断。
- **K2期间：** 本地路径按目标小学已公布日程执行；英基家庭按其K2升Year 1程序办理。部分校本小学报名较早，须提前持续查看。
- **进入K3前后（本地三年幼稚园路径）：** 按当届官津小一日程办理派位及尚在进行的校本申请；已经结束的招生不会因进入K3重新开放。
- **小学入学前：** 交接学习与支援资料，帮助孩子认识新环境，不以提前学习小学课本代替适应。

同样是希望孩子将来有更多选择，一些家庭当前最需要的是稳定的照顾与粤语生活环境，另一些需要连续的英语课程，还有些应先寻找能支持儿童发展的学校。远期规划应当帮助家长分配今天的时间与资源，并随着孩子成长继续修订。

## 家庭可以直接填写的一页规划表

这张表用于把远期愿望转成可执行条件。父母可以先分别填写，再比较分歧；不需要给孩子预测职业。

| 讨论项目 | 请写下家庭目前的答案 |
|---|---|
| 未来三至五年主要生活地点 | 已经确定的安排是什么？还有哪些可能变化？ |
| 希望孩子拥有的日常 | 希望有多少自由游戏、运动、阅读及家庭相处时间？ |
| 下一阶段优先考虑的两条路径 | 各自为什么值得保留？哪些只是跟随其他家长的焦虑？ |
| 家庭能提供的语言环境 | 谁能持续陪伴中文、英文阅读？谁能帮助理解学校通知？ |
| 三年可持续预算 | 每年学校与照顾开支分别多少？一次性支出和持续支出各是什么？ |
| 每天交通与接送 | 谁送、谁接？临时加班、疾病或校车停驶时怎样安排？ |
| 孩子的实际需要 | 哪些来自日常观察，哪些已有专业意见，哪些仍需了解？ |
| 必须取得书面答复的事项 | 年龄、衔接、退费、转校或支援中，有什么仍不清楚？ |
| 下一次复盘时间 | 在哪个学期或家庭安排改变后重新讨论？ |

填写时尤其注意两种落差。第一，父母说“希望孩子开心”，但选择条件全部围绕升学结果；此时需要讨论，家庭愿意怎样安排每一天。第二，父母说“希望保留海外选择”，但没有为语言学习、未来学费或迁居做任何准备；此时应把愿望拆成逐年可调整的行动。

筛选学校也可以分三步。先排除当前无法满足的硬条件，例如年龄不合、接送无法安排或费用不能持续承担；再比较孩子在课堂中能否理解、参与及获得支持；最后比较办学理念和后续衔接。这样，远期目标会成为比较依据，不会取代眼前的生活需要。

收到录取时，可以重填一次这张表：当初预计的居住地点、工作时间和费用有没有变化？另一所学校的候补是否值得继续等？现有学位的取消和退费条件是否已经读懂？不要因为报名时把某校排第一，就忽略注册时家庭条件已经改变。

## 术语速查

| 词语 | 含义及使用边界 |
|---|---|
| PN／N班／N1 | 机构对幼稚园前阶段服务的常见称呼，查年龄与正式班名 |
| K1／K2／K3 | 本地幼稚园幼儿班／低班／高班；英基通常为K1、K2后升Year 1 |
| 英基／ESF | 英基学校协会，在香港营办幼稚园、小学及中学，并非国际学校统称 |
| 大B／细B／超大B | 同届相对年龄或延后入学后的民间说法，先确认出生年月及比较届别，不是能力评级 |
| 非牟利／私立独立 | 幼稚园办学性质；非牟利不等于免费 |
| 计划园／券园 | 通常指参加现行幼稚园教育计划的学校，另查孩子资助资格 |
| 学券 | 历史制度称呼；现行需查幼稚园教育计划 |
| 计划幼稚园 | 参加幼稚园教育计划的学校，不等同官立学校 |
| 注册证／RC | 幼稚园入学注册证，不等同学校offer |
| 入学许可书／AP | 可就读但不符合相关资助资格儿童使用的注册文件，须经审核 |
| 统一注册 | 相关K1收生安排的注册窗口，不是统一分配学校 |
| 校本收生 | 学校依本校公开机制处理申请，不代表没有规则 |
| 正取／备取 | 录取／候补，具体回复与注册条件看书面通知 |
| offer／conditional offer | 录取／附条件录取，查条件及期限 |
| call wait／候补获通知 | 非统一民间用语，通常指候补获联系；具体是否录取看学校通知 |
| 留位费 | 口语可能泛指注册或保留学位费用，必须确认正式收费名称与条款 |
| 龙幼 | 民间衔接标签，须查对象、条件及是否保证指定小学 |
| 两文三语 | 中文与英文书面语，粤语、英语和普通话口语 |
| NET | 常见指英语母语教师，聘有NET本身不能说明每日英语接触量 |
| SEN | 特殊教育需要；具体支援须看评估、儿童需要与学校措施 |

## 家长常问的五个问题

**没有读PN，会不会不能申请K1？**

不要把个别机构的内部升班安排当成全港前置要求。按目标学校的公开K1资格申请；有无PN、是否同校及相关优先安排须分别核实。

**住哪个区就必须报哪个区的幼稚园吗？**

K1校本申请不能套用小一统一派位乙部的校网概念。以具体学校招生条件为准，比较实际路程和家庭安排。

**注册证还在审批，可以先向学校报名吗？**

两项程序应并行管理；报名材料依学校要求，完成注册时须具备相应有效文件。若文件可能赶不上注册，及时向教育局及学校查询，不能自行假定录取信能代替。

**普通话家庭是否等于“非华语家庭”？**

不要把不懂粤语、在内地出生、非华语儿童和非本地儿童画等号。向学校具体说明儿童理解及使用的语言，再查询适用支援。

**现在是否需要替孩子选好大学和专业？**

可以讨论家庭愿意支持的生活地点、语言与费用范围，但幼稚园阶段没有必要据此锁定专业。未来课程、个人兴趣、大学及身份相关规则都会影响申请；保留持续学习和调整的能力，更适合这个阶段。
