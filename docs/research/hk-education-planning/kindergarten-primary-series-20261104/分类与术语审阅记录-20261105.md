# 幼稚园与小学指南：分类和术语审阅

核对日期：2026-11-05。范围为两份长指南以及网站六篇短文的术语和结构；本轮修订长指南另存，原文件保留。网站两个系列首篇补充分类型定义，其余四篇已核查标题和对应解释，不为重复解释而强行增文。

| 项目 | 原问题与处理 | 边界 |
|---|---|---|
| 幼稚园办学 | 原稿列非牟利、私立独立但定义和区别不足；补办学性质与收费、招生关系 | 非牟利不等于免费；全部私营不等于全部私立独立 |
| 幼稚园教育计划 | 补计划园、非计划园和券园；解释非牟利未必参计划 | 学校资格、儿童资格、额外学费减免分别核实 |
| 幼稚园暨幼儿中心 | 补幼稚园与社署幼儿中心服务的区别 | 不由名称推断PN开班、年龄或空位；现行社署服务对象为三岁以下 |
| 国际／双语／时段 | 补课程与语言、办学性质和服务时长交叉关系 | 国际不自动代表IB；双语不代表五五分配 |
| 大B／细B／超大B | 长指南原文未解释超大B，补计算例子并与入学届别绑定 | 民间月份划分不统一，不能推断能力或取录 |
| 学券、RC/AP、正取备取、龙幼 | 原文术语表及招生／注册／衔接章节已解释 | RC/AP不是学校offer；龙幼不自动保证学位 |
| 官立／资助／直资／私立 | 补政府或办学团体、资助与费用、招生办法的区别 | 学费免费不包括全部费用；直资接受学位的后果须按当届规则 |
| 国际／英基／课程 | 解释国际是课程定位描述、英基为机构，可能与其他类别交叉 | 校名不自动代表IB；DSE、IB与A-level的阶段在正文另释 |
| 自行、必收、计分、甲乙部、校网、叩门 | 长指南正文及速查已有定义；系列第2、3篇按步骤细解 | 小一与升中校网、随机分配及计分分母不能混用 |
| 直属、联系、一条龙、呈分、TSA、Band | 长指南升中章节与速查已有解释；系列第三篇另列 | 民间学校Band标签不等于学生派位组别 |
| 插班、offer、waiting list、JUPAS | 长指南及系列有关章节已有解释 | 升学身份、大学申请渠道、学费资助不能混为一谈 |
