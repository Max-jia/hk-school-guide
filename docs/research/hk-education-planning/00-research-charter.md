# 香港教育規劃影片系列｜研究總綱
> 版本：0.7（持續研究版）
> 研究基準日：2026-10-10（香港時間）
> 目標：形成幼稚園至大學／專上教育及就業出口的可查證研究底稿，支援一套長期更新的香港教育規劃影片系列。
> 語言：本底稿採香港繁體中文；面向內地來港家庭的影片可另製簡體字幕或版本。
> 狀態：核心制度研究底稿已涵蓋K1、P1、POA、小學課程與支援、SSPA、本地S1–S6／HKDSE及中學後主要本地路徑與資助制度；EDB S6 2021–2025 Tables 2.1–2.3及Chart 2.5已抽取並作跨年口徑對照。中學後量化資料主工作簿維持v1.1（316項指標、32項原工作簿來源、29列人口／事件交叉表）；另建畢業生去向專項來源登錄v1.2（45列含標題、44項來源）及觀察值CSV。SNDAS第五屆接受offer學科附件已抽取19類、合計319人；英文學科名按官方原文修正，兩個單一人數格仍待原PDF版面核對。畢業生去向已完成第一輪指標定義審核（報告27），但UGC最新全量資料逐列抽取、共同分母／回覆率核對、VTC分層資料及跨院校可比分析未完成，不做校際排名。仍未完成：2026 HKDSE 30,977／約73.2%精確子群分母、JUPAS全體offer接受／繳費及註冊aggregate、SNDAS接受者開學後實際註冊確認、逐校抽樣、國際課程比較及跨學段長期供需序列。各缺口不得以估算或其他母體代替，詳見報告19、22、24、26、27及工作簿「待提取」。

## 1. 研究原則

本研究不是「名校排名」或「入學秘笈」合集，而是家長在不同學段作教育決策的制度地圖。每項重要內容都應回答：

1. 規則是甚麼，適用哪一學年、哪類學校及哪類學生？
2. 家庭在哪個時間點需要行動，遲交／不符合資格有何後果？
3. 學校和課程的公開資料能證明甚麼、不能證明甚麼？
4. 有哪些費用、日常安排、支援需要和替代路徑？
5. 數據的年份、統計口徑、分母和限制是甚麼？

### 證據標籤

- **制度事實**：政府、考評局、聯招或法定機構的規則／原始文件。
- **院校公開資料**：學校或院校對課程、收生、費用、支援及升學結果的公告；只代表該校／該課程／該年度。
- **官方統計**：官方統計表、調查或行政數據；必須保存年份、統計對象、定義和分母。
- **研究發現**：由多個來源支持的趨勢或比較；說明方法和不確定性。
- **專業建議**：以制度和證據為基礎提出的決策方法，不是官方政策或錄取保證。
- **待核實**：官方材料不足、口徑不一致、仍待逐校確認或存在身份／法律判斷的問題。

任何「名校偏好某類家庭」「活動會加分」「某區一定容易派位」「某課程保證升大學」等說法，沒有可追溯的當年原始證據就不得作普遍結論。個案、家長分享和市場傳聞只能作為待驗證線索。

## 2. 研究範圍和終點

### 核心縱向路徑

幼稚園 K1–K3 → 小學 P1–P6 → 中學 S1–S6 → 中學後多元出口 → 大學／專業資格／就業及持續進修。

### 全程橫向議題

- 官立、資助、按位津貼、直資、私立、國際學校及英基等學校類型；按具體制度說明其差異，不把某類型簡化成「好／差」。
- 香港本地課程及公開考試、IB、英國及其他海外課程；拆分「課程內容、考試資格、大學入學認可、實際可選課程」四層比較。
- 香港居民及不同居留／入學資格、跨境通學、新來港及非華語家庭；身份涉及法規時只列官方查核入口，不代替法律意見。
- 特殊教育需要（SEN）、資優、身心健康、融合教育、特殊學校支援及學段轉銜。
- 中文／英文／普通話語言規劃、學習支援、家校溝通、交通與作息。
- 學費、債券／建校費（如有）、校服書簿、交通、膳食、活動、考試、補習、寄宿／住宿及升學申請等總成本。
- 教育人口、出生人口、校額供需、學校開辦與收生變化，以及本地／非本地升學和勞動市場出口。

## 3. 核心研究問題樹

### A. 全港制度與供需

1. 各學段的法律／政策框架、主管機構和資格邊界是甚麼？
2. 各類學校的資助、收生自主、課程、收費及質素保證方式如何不同？
3. 近十年出生人口、學生人數、學校數目、班級／學額及教師供應如何變化？不同學段和地區是否不同？
4. 供需數據能否用來解釋家長的實際選擇？哪些是全港數字、哪些必須拆到校網／地區／年級？
5. 官方資料與校方公布的統計是否使用可比較的年度、分母和定義？

### B. 幼稚園 K1–K3

1. 幼稚園教育計劃涵蓋哪些學校／學額？非參加計劃、私立獨立及國際幼稚園如何處理？
2. K1入學註冊證／電子申請、收生時間線、學費減免／豁免、雜費和學位空缺資料如何運作？
3. 面試和收生方式由哪些政府指引規範，哪些屬學校自主安排？
4. 如何比較課程、語言、照顧時段、師生安排、校舍、交通、家校協作和支援？
5. 哪些幼兒發展準備有教育意義，如何避免把幼兒教育變成小學面試操練？
6. 幼稚園不直升小學時，幼小銜接需重新準備甚麼？

### C. 小學 P1–P6

1. 小一入學統籌辦法（POA）的自行分配、統一派位、校網、計分準則及跨網申請如何按年度運作？
2. 哪些學校不在POA內，直資／私立／英基申請如何與POA時間線並行？
3. 「校網、地址、世襲／計分、統一派位志願」各自影響甚麼，哪些常見說法容易誤導？
4. 小學公開資料應如何比較課程、語言、評估、支援、校風、升中銜接、交通和總成本？
5. P1適應、P2–P4基礎、P5–P6升中準備各有哪些適齡目標？
6. 若未獲理想學位、轉校或搬遷，家長的合法和實際備選方案是甚麼？

### D. 中學 S1–S6

1. 中學學位分配（SSPA）的自行分配學位、統一派位、校網、派位組別、隨機編號、直屬／聯繫學校安排如何互相作用？
2. 直資參加／不參加SSPA、私立和國際中學的申請及註冊期限如何與派位並行？
3. 學校公開的收生準則、校本評核、面試、成績及升學結果能支持哪些比較？
4. S1–S3如何看學習適應和支援；S4–S6如何按學科能力、興趣和升學出口選科？
5. DSE科目架構、校本評核、應用學習、其他語言和考試評級應如何準確解釋？
6. IB、A-Level及其他國際課程需要哪些先修科目、考試安排和家庭成本，如何對接不同大學？
7. SEN、非華語、資優及精神健康支援如何跨學段銜接？

### E. 中學後出口及大學

1. JUPAS、非聯招、聯招以外院校申請、內地升學、海外申請的資格、時間線及材料有何差異？
2. 本地資助學士、自資學士、SSSDP、副學位、高級文憑、基礎課程及職專路徑的入學要求、成本和銜接證據是甚麼？
3. DSE、IB、A-Level等資格被各院校及科目採納的條件如何查證？
4. 主輪取錄、改選、成績覆核後重審、補錄／Clearing等程序如何形成時間風險？
5. 學生資助、貸款、獎學金、宿舍、交通和生活費如何影響實際可行性？
6. 畢業生升學／就業統計如何看樣本、回覆率、調查時點、學科差異和非本地生身份？
7. 未獲學位或不適合傳統學士路徑時，職業專才教育、資歷架構、在職培訓及重新升學有甚麼可逆路徑？

### F. 家庭決策方法

1. 如何以家庭目標、預算、居住地、身份、語言、孩子需要及風險承受度建立候選池？
2. 如何做「首選／可接受／備選」而不虛構錄取率或稱某校為個人保底？
3. 如何建立時間線、申請材料台帳、費用預算、風險預警及 Plan B？
4. 如何在孩子能力與福祉、家庭財務、交通時間和升學出口間作可持續取捨？

## 4. 研究工作流與交付

### Phase 0｜研究基礎設施（本輪啟動）

- 完成本研究總綱、問題樹、證據標籤、初始官方來源索引。
- 建立來源台帳、年度版本欄位、統計指標字典和影片主張查核模板。
- 盤點現有專案研究文件與已建教育規劃功能，避免重複研究或覆蓋既有工作。

### Phase 1｜制度骨架與年度資料（先行）

- 研究幼稚園收生／資助、POA、SSPA、S4相關分配安排、DSE、JUPAS與職專出口的現行規則。
- 以2026/27及已公布的2027/28資料標示當前週期；完整規則以最新原文、通告、表格和FAQ為準。
- 交付：制度路徑圖、年度時間線、資格與排除條件、關鍵錯誤風險表。

### Phase 2｜官方統計與人口供需

- 抽取EDB學生人數、學校數目、各學段／地區統計、POA/SSPA年度分配報告、S6出路調查、DSE成績／考生數、JUPAS offers、UGC招生和畢業生數據、國際學校統計、政府教育開支及學生資助數據。
- 以可比年份做時間序列；如口徑、政策或分類改變，拆段而不強行拼接。
- 交付：來源可追溯的數據工作簿、指標字典、圖表草稿、缺口與不可比較清單。

### Phase 3｜課程與院校出口

- 比較DSE、IB、A-Level及主要其他資格的課程／考試／大學認可條件。
- 建立本地大學、非大學專上、職專和海外／內地路徑矩陣；逐項記錄院校、課程、學年、申請期限、要求、費用及官方來源。
- 交付：路徑選擇矩陣、申請材料清單、成本和可逆性比較。

### Phase 4｜學校與家庭實際決策

- 建立學校類型比較框架；再按明確研究範圍選擇地區／代表學校做當年公開資料個案，避免無限量地列全港學校。
- 設計一般家庭資料模板，不替沒有具體住址／身份／預算的家庭判定個人錄取概率。
- 交付：選校評估卡、家庭資料清單、候選池方法、風險與Plan B案例。

### Phase 5｜影片編排與主張驗收

- 將觀眾問題分成「主線制度」「實際決策」「年度更新」三類。
- 每集需要：明確觀眾問題、適用年級／週期、核心結論、證據鏈、常見誤解、行動清單、限制聲明和更新責任。
- 交付：系列總目錄、集數研究簡報、首批腳本、片尾來源卡與更新日曆。

## 5. 資料庫欄位規格

### Source Register（每條來源一筆）

`source_id, title, publisher, source_type, URL, published_at, retrieved_at, applicable_school_year, applicable_cohort, language, source_level, claims_supported, exact_location/table/page, limitations, recheck_due, status`

### Claim Ledger（每個影片主張一筆）

`claim_id, proposed_claim, evidence_label, source_ids, exact_wording_boundary, year_scope, population_scope, denominator, caveat, reviewer, verification_status, episode_id`

### Quantitative Dataset（每個觀察值一筆）

`indicator_id, indicator_name, year, stage, school_sector, district, numerator, denominator, unit, value, definition, source_id, comparability_notes`

統計數字不得只存一個百分比；須盡可能同時保存分子、分母、單位和來源頁碼／表號。金額需存幣種、學年、一次性／每年／每月、是否含住宿／雜費、資助前後和適用資格。

## 6. 影片系列初步分層（非最終集數）

1. **總覽篇**：香港教育不是單一路線；先理解制度和家庭決策變數。
2. **幼稚園篇**：K1制度、收生、資助、比較幼稚園及幼小銜接。
3. **小學篇**：POA、校網、學校類型、六年準備和備選。
4. **中學篇**：SSPA、課程與校本收生、S1–S6分階段策略。
5. **課程篇**：DSE、IB、A-Level及資格對接，而非只比名氣。
6. **大學與多元出口篇**：JUPAS、非聯招、副學位、職專、內地／海外升學及資助。
7. **橫向專題篇**：SEN／非華語、家庭財務、跨境／轉校、升學數據讀法、名校傳聞核實。
8. **年度更新篇**：POA、SSPA、K1、DSE、JUPAS和學費等有版本的資訊。

實際集數和次序應在Phase 1–3完成後，依觀眾需求與研究證據調整；不以「集數多」代替覆蓋完整。

## 7. 品質門檻與風險控制

- 動態事實用明確學年，不用「現時」作永久標籤；規則頁／申請頁優先於舊文章和搜尋摘要。
- 不以一所學校的做法外推全港；校方宣傳中的「升學率」「就業率」要核查分母、調查期、課程範圍和是否由第三方審計。
- 不以中學文憑、JUPAS applicants、offers或學校排名直接推導個人成功概率。
- 不把錄取結果、家長故事和地區派位回憶當成因果證據。
- 不能把「資助」等同免費；學費以外要計算全成本。
- 涉及身份、居留、跨境、法律資格和學生資助資格時，以最新政府原文為準，必要時建議向主管部門查詢。
- 教育規劃建議須尊重孩子發展、健康及意願，不鼓勵幼兒過度操練或無差別堆砌履歷。
- 使用「15年以上專家」作個人品牌主張前，應以本人可核實經歷支持；研究底稿只支持內容可信度，不證明個人年資。

## 8. 首輪研究盤點後的初步判斷（待完整數據分析）

1. 官方資訊不是一個集中入口：幼稚園、小學、中學、考試、大學、職專和資助機構各有年度頁面，研究需要自己的版本索引。
2. 教育規劃的核心難點是「時間線和路徑交錯」：一個家庭可能同時申請不參加統籌辦法的學校、處理POA/SSPA，並要保留註冊、退出和備選期限。
3. 出口研究不能停在大學。教育局S6出路調查和VTC/HKQF資料顯示，必須把副學位、職專、應用導向學位、持續進修與就業納入同一張路徑圖。
4. 地區供需、身份資格、特殊需要和家庭總成本不能只放在附錄；它們可能改變路徑本身。
5. 現有數據表明，觀眾容易把不同分母混為一談（例如DSE考生、JUPAS申請人、JUPAS主輪獲offer者、S6畢業生、全日制升學者），影片必須反覆提示統計口徑。

上述是研究設計判斷，並非已完成的供需結論。供需、人口和院校比較需待抽取官方年度序列後再判斷。
