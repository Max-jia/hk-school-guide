# 中学深度报告写作与验收标准

适用范围：本项目现有及以后新增的所有中学报告。此标准补充逐校事实核验规则；小学报告的叙述方式可借鉴，但「升中通路」「小一入读」等小学章节不能照搬到中学。

## 先研究，再判断

每校先建立证据表，覆盖学校身份、教学与语言、高中路线、公开试与实际升学、收生、费用、学生支援、家长体验和同类校比较。学校事实以校方、教育局、家校会概览和考试机构为底数；关键数值交叉核对年份、分母与统计单位。媒体、教育王国及社交讨论用于补充体验和争议，须记录日期、链接、身份可核程度；匿名评论无需伪装成多方证实的事实。查不到就明说，不能由 offer 数推算入学率，也不能把「达到大学门槛」写成「获大学取录」。

## 每章的编辑动作

每章开头先写该校的**定位判断**，然后按「已核事实 → 对哪类家庭有价值 → 相应代价或风险 → 一个可执行动作」展开。表格承载数据，正文负责解释；正文不能重复读表。家庭情境须具体到孩子学力、语言、性格、路线、预算或通勤，不写适用于任何学校的空泛建议。结论可以明确，但必须有条件。

| 章 | 必答问题 |
| --- | --- |
| 1 定位与竞争力 | 这校在同区或同类学校中提供了什么独有组合？非官方 Band 定位有何共识或分歧？谁该优先、谁不该？ |
| 2 中一入读 | 当届怎样申请、评核什么、关键节点与承诺是什么？孩子和家长按什么顺序准备？ |
| 3 教学与路线 | 逐科教学语言、评估节奏、选科与 DSE／IB／IAL 分流会怎样改变孩子每天的学习？哪些路线有名额或转换限制？ |
| 4 升学出口 | 公考成绩、大学申请、offer、取录、最终入读各自是什么口径？目标院校层级、连续年份和分母怎样影响判断？ |
| 5 费用与投入 | 六年学费、课程差价、交通、活动与资助怎样影响真实预算？不同路线的投入与回报如何取舍？ |
| 6 在读体验 | 家长／学生评价具体讲了什么，哪些只是校方安排？功课、压力、师生关系、活动、通勤及支持如何落到日常？正反意见和样本边界都要保留。 |
| 7 同类比较 | 至少三校用同口径比路线、费用、地点、入读方式及适合的孩子；用条件句分流并给备选。 |
| 8 专家结论 | 是否值得读、适合谁、最大风险、录取或路线不合时的 Plan B，以及当下第一步。FAQ 可保留，但不能代替结论。 |

## Band 定位与评级

教育局为派位学生划分组别，并不发布「学校 Band 1A／1B」名单。中学报告把**坊间学术定位**与本平台综合评级分开，不以学生派位组别或单一网站排名推定学校 Band。至少查两种独立来源，并用学校近年公开试表现、课程和收生机制检视其解释力；共享同一底层排名的网站不能算多方独立验证。若估计分歧，直接展示区间与分歧，不凑成精确标签。国际课程学校或证据不足时标「不适用／暂无可靠共识」。标注年份、来源及「非官方」，不要把 Band 当录取机会、大学去向或教育质量的保证。

## 交付门禁

逐校核对八章结构、事实与年份、来源可点击、非官方判断标识、家长体验证据边界、重复段落、章节标题长度、移动端表格与页面渲染。保留已核的好内容；删去重复事实和通用套话。完成研究、内容审计、去 AI 味编辑及渲染验收后才提交用户查看。先交一所样稿，取得确认后再按同一标准推进其余学校。
