# 小一志愿模拟器 v2：决策工作台（不是报告生成器）

> 日期：2026-09-09 | 定位：一个能反复"试错"的决策工具，报告只是抄表用的导出物
> 底线：不预测录取概率（随机编号不可模拟）——用「相对竞争烈度 + 顺序推导 + 预案」替代概率，既是合规也是人设

## 一、定位纠偏：工具 vs 报告

工具 = 决策工作台：用户在上面排志愿、调顺序、立刻看到结果怎么变，可以反复试错。
报告 = 工作台的结果导出（一页纸方便抄表/存档），是工具的一部分，不是工具本身。

付费解锁的应该是**高级决策能力**（顺序引擎 / 滑档模拟 / 逐校标签 / 预案），
而不是"交付一份 PDF"。PDF 只是让能力可带走。

这就是"试错"——把乙二换成另一所，马上看到滑档线往哪挪。

## 三、六大决策能力（付费核心）

### 1. 底牌分析（常驻）
计分自动拆解（已有）+ 网内格局读数：N 所 / 学额中位数 / 稀缺校清单 + 自行分配「可冲/需守」建议（结构建议，非预测）。

### 2. 乙部顺序引擎（实时）
根据当前排序给"结构建议"：
- 乙一：冲刺且学额不极端稀缺（最想要又够得着）
- 乙二：必须守得住（乙二仍冲=滑档高发）
- 保底：必须在前 60% 位置（10 所网 → 不晚于第 6 位）
- 差异标红：当前顺序 vs 建议顺序的不同之处，逐项解释

### 3. 滑档模拟（实时可视化）
按当前顺序逐步推导，用学额稀缺度标每个位置的风险档：
- 滑档线：第几志愿起相对充裕、大概率能中（相对概念，不是概率）
- 最坏落点：前 N 个稀缺校全落空会到第几志愿
- 调整顺序 → 线条实时移动 → 用户"看得见"安全排序

### 4. 网内学校体检（联动高亮）
合并 schools.json + p1-nets：
性别 / 宗教 / 班制 / 学费参考 / 升中通路（一条龙/直属/联系）/ 学额稀缺 / 小班
不匹配自动标「填了也白填」；选到不匹配学校时实时提醒。

### 5. 三套预案
叩门 72h（3 间目标+材料）· 直资插班窗口（呈分试前）· 注册时限（逾期视为放弃）

### 6. 导出与复购
- 决策报告 PDF（抄表用）+ 抄表卡
- 方案存档：保存多套顺序对比（A/B 方案）
- 每年 9 月数据更新，旧客户优惠续新

## 四、小白 vs 懂行：双模式

- 小白模式：「我不知道怎么排」→ 一键生成建议顺序 + 每步解释，照抄即可
- 懂行模式：完全自定义，工具只做体检 + 差异标红 + 滑档线，不打扰

免费（钩子）：计分 + 数量/保底/重复粗检 + 校网数据库
Pro（¥49-99）：能力 1-6 全开 + 导出 + 多方案存档

## 五、不可碰的底线

1. 不做录取概率预测——滑档模拟是顺序推导+相对烈度，不是"你有80%中"
2. 不替家长决定最爱哪所——工具检查结构，建议顺序可改可忽略
3. 缩班不写具体名单——无官方权威名单，只提示「核对开班数」
4. 所有数据标注来源（教育局名册/FAQ/新闻公布/本站整理）
